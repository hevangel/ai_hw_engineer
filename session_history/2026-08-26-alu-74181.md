## Specification and RTL

- Stored TI and Fairchild datasheets in `design/alu_74181/spec/`.
- Converted the device behavior into `spec/spec.md`, covering pinout, active-HIGH and active-LOW function tables, carry/lookahead equations, comparator behavior, electrical/timing data, package information, and usage notes.
- Corrected selector mapping and negative-logic interpretation during datasheet review.
- Implemented a purely combinational IEEE 1800-2017 module in `src/alu_74181.sv` using the datasheet X/Y carry-lookahead equations.
- Implemented mode-dependent `F` polarity, active-LOW `Cn` and `Cn+4`, active-LOW `P_bar` and `G_bar`, and `A=B = &F`.
- Independently derived the active-LOW table as `F_low(A,B) = NOT F_high(NOT A,NOT B)` and checked 4,096 logic plus 8,192 arithmetic/carry cases.

## Verification environment

- Added a UVM 1800.2-2017 interface, sequence item, all-mode sequence, sequencer, driver, monitor, scoreboard, environment, test, and top module.
- Added a formal harness with no functional input assumptions, packed output equivalence assertions, a symbolic sampling boundary, and ten non-vacuity covers.
- Added deterministic `run_lint.sh`, `run_sim.sh`, `run_formal.sh`, `run_synth.sh`, `run_coverage.sh`, and `run_all.sh` entry points.
