## Key decisions

1. **Width 10, not 16.** The task brief said "16-bit shift register with 16
   parallel I/O lines". Primary sources are unanimous that the 4003 is a
   10-bit part (MCS-4 Users Manual Feb 1973 section VI, Nov 1971 data
   sheet, IEEE "History of the 4004" by Faggin/Hoff/Mazor/Shima, MAME's
   Busicom driver with its 0x3FF mask, TAMS Hades notes), and the 16-pin
   DIP only fits with ten parallel outputs. Implemented 10 bits; `WIDTH`
   stays a parameter for verification experiments only.
2. **Serial 1-bit load, not nibble load.** Considered and rejected a
   per-instruction nibble-load model: the part is loaded bit-serially
   through a port line under program control. The CPU's 4-bit port nibble
   is demultiplexed on the board (bit 0 CP, bit 1 DATA IN, bit 2 ENABLE —
   the wiring MAME's Busicom driver uses).
3. **Synchronous reconstruction additions.** `clk` and `rst_n` replace the
   free-running nature and the internal power-on-clear; CP is edge-detected
   synchronously, which reproduces the datasheet contract "DATA IN and CP
   can be simultaneous, CP internally delayed" (exactly one shift per CP
   pulse, data sampled at the edge ending the first CP-high clock period).
4. **Enable polarity.** `en_i` active-high in RTL = the manual's negative
   logic convention for the active-low-voltage ENABLE pin; disabled outputs
   map to all-zero bits (the historical deasserted Vgg level).
5. **Cascade is external wiring** (SERIAL OUT → DATA IN, shared CP/E), not
   a parameter — matching the manual's "length multiples of 10" chaining.

## Issues found and fixed during verification

- **bmc counterexample at frame 3**: the original reset assertions demanded
  a cleared register in the cycle reset is (re-)asserted, ignoring
  synchronous-reset latency. Properties corrected (RTL unchanged) to assert
  the clear in every cycle following an edge that sampled reset low; spec
  section 8 reworded.
- **Verilator `-Wall` UNUSEDSIGNAL in the TB**: restructured the bus master
  so the port model derives its phase from SYNC (as real chips do);
  genuinely unwired port lines quarantined behind a documented lint waiver.
- **Cover-count gate bug in `run_coverage.sh`**: comparison threshold
  mismatched the final cover count (33); fixed.
- A 4th-pass sby trace-replay wanted `yices` (not in the image) to display
  the abc counterexample; replayed manually with `yosys-smtbmc -s z3` to
  identify the failing properties.
