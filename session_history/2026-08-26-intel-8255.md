## Goal

Build the Intel 8255/8255A Programmable Peripheral Interface as a complete historical chip design under `design/intel_8255/`, including a sourced specification and README, implementation and verification plans, synthesizable SystemVerilog RTL, deterministic simulation, formal verification, generic synthesis, fail-fast scripts, reports, design-index integration, semantic review, and reproducible sign-off evidence.

## Architecture and scope

- Implemented a single-clock functional reconstruction of the 8255A programming model.
- Implemented Mode 0 simple I/O, both Group A and Group B Mode 1 directions, Mode 2 bidirectional Port A, Port C handshake/status ownership, BSR, hidden INTE controls, IBF/OBF state, interrupts, and reset-to-input behavior.
- Exposed bidirectional pins as separate input, output, and per-bit output-enable vectors.
- Used active-high synchronous reset to preserve the historical RESET polarity while making state updates portable and synthesizable.
- Sampled active-low CPU strobes and peripheral handshake transitions on `clk`.
- Explicitly excluded asynchronous pin/timing equivalence, analog behavior, package behavior, and metastability hardening. Integration must synchronize genuinely asynchronous handshake inputs.

## Implementation and verification

- Added `design/intel_8255/src/intel_8255.sv` as the synthesizable core.
- Added a deterministic procedural testbench with a separately organized reference state model, specification-derived black-box protocol checks, directed scenarios, and a fixed-seed 1,024-operation stress regression.
- Added explicitly connected formal properties for visible-interface equivalence and sequential reset, mode-set, BSR, input capture/read, output write/acknowledge, INTE, interrupt, and conflict priorities.
- Required reset only in the initial formal cycle; later resets and all bus/peripheral inputs remain unconstrained.
- Added a separate lightweight formal coverage module with 12 causal/non-vacuity covers.
- Added fail-fast lint, simulation, formal, synthesis, coverage, and aggregate scripts.
- Added the chip README, specification, implementation plan, test plan, formal plan, coverage report, final report, and sourced `design/README.md` index entry.

## Semantic-review remediation

The initial semantic review returned `NOT READY` because Mode 2 Port A output enable followed pending-data `OBF_A_n`. The implementation was corrected end to end:

1. Port A now drives only while PC6/`ACK_A_n` is low; `OBF_A_n` remains the pending-output indication.
2. The testbench reference and specification-derived directed checks enforce ACK-high release, ACK-low drive, and release when ACK returns high.
3. The formal output oracle directly asserts ACK-controlled Mode 2 ownership.
4. Formal assumptions were strengthened to permit arbitrary later reset assertions.
5. Reachability was expanded from 10 state-oriented covers to 12 causal protocol and conflict covers.
6. Reports were corrected to avoid claiming the reference state model is fully independent.

Final semantic re-review returned `READY` with no blocking, major, or minor findings.
