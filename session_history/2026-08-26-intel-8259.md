## Goal

historical chip design under `design/intel_8259/`, including a sourced

SystemVerilog RTL, deterministic simulation, formal verification, generic

## Architecture and scope

- Implemented a single-clock functional reconstruction of the 8259A programming
  model as one module, `design/intel_8259/src/intel_8259.sv`.
- Implemented ICW1-ICW4 initialization sequencing (single and cascade), OCW1-OCW3
  operation commands, edge/level request sensing, the IRR/ISR/IMR registers, a
  rotating priority resolver, the CPU acknowledge sequence in both MCS-86/88
  (two pulses, vector byte) and MCS-80/85 (three pulses, `CALL` opcode and two
  address bytes) modes, non-specific/specific/rotate EOI and set-priority,
  automatic EOI and rotate-in-automatic-EOI, special fully nested mode, special
  mask mode, polled mode, IRR/ISR/IMR readback, cascade signaling, and buffered
  mode.
- Exposed the shared cascade and buffer-enable pins as separate input, output,
  and output-enable signals.
- Added an active-low synchronous `rst_n` to establish a defined un-initialized
  state; documented that the historical device has neither a clock nor a reset
  pin and is initialized only by the ICW1 sequence.
- Excluded asynchronous pin/timing equivalence, analog and NMOS/TTL behavior,
  package behavior, metastability hardening, and full multi-chip system timing.

## Implementation and verification

- Added a deterministic procedural testbench,
  `design/intel_8259/tb/tb_intel_8259.sv`, with a separately organized
  cycle-accurate reference model, specification-derived black-box protocol
  checks (vector formula, priority nesting, EOI clearing, poll word, cascade
  signaling), directed scenarios for every documented feature, and a fixed-seed
  2,048-operation stress regression.
- Added explicitly connected formal properties,
  `design/intel_8259/formal/intel_8259_props.sv`, covering combinational output
  equivalence and structural safety plus sequential reset, ICW1, mask-update,
  and specific-EOI transitions; reset is assumed only in the initial formal
  cycle.
- Added a scripted-stimulus non-vacuity cover harness,
  `design/intel_8259/formal/intel_8259_cover.sv`, with eight reachability
  covers.
- Added fail-fast lint, simulation, formal, synthesis, coverage, and aggregate
  scripts.
- Added the chip README, specification, implementation plan, test plan, formal
  plan, coverage report, final report, and the sourced `design/README.md` index
  entry.

## Engineering notes

- The priority resolver was implemented as a candidate-mask rotation followed by
  a fixed lowest-index priority encoder returning `{valid, rank, level}`. This
  is behaviorally identical to modular-arithmetic ranking but far easier for
  both AIG and SMT reasoning; the change was verified equivalent by the
  unchanged, passing simulation.
- The AIG-based ABC engine used for BMC and unbounded proof converges in under a
  second on this design. SBY does not support cover mode with ABC, and the only
  available SMT solver (Z3) does not scale on this circuit's default cover
  encoding. Cover was made fast and deterministic by enabling the `--unroll`
  option and constraining the cover environment to a single scripted stimulus
  trace with a cycle counter. Unconstrained random reachability is provided by
  the simulation regression.

## Historical record

The design index and chip README record **1976**, the year the 8259 was
introduced as part of Intel's MCS-85 family, per the cited historical summary.
The exact commercial launch date within 1976 was not established, so the year is
recorded rather than a month-level date; the uncertainty is retained. The later
8259A added 8086/8088 mode and became a fixture of the IBM PC/AT interrupt
architecture. Technical behavior is sourced from an Intel 8259A datasheet
reproduction and Intel's "Programming the 8259A" application note.
