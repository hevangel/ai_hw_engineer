## Remaining work, in priority order

### 1. Make the release gate finish in one pass

`run_formal.sh` runs the connected-core cover (`formal/intel_80286.sby`,
`cover: depth 64`, yices) before every non-formal stage, and it never
completes (reports 2026-11-05: 45 of 89 covers in 55.6 h; 2026-11-01: 22 h
at step 33). Options to evaluate, without weakening any property:
split the 89 covers into separately bounded tasks, move covers that are
reachable early to a shorter-depth task, try another solver or engine
(`smtbmc boolector`, `abc` where applicable), or run the core cover as a
separate long job whose result `audit_formal.py` checks. Whatever is chosen,
the gate must still require every cover to be reached, and the formal plan
and final report must say what is proved. The PDR job (`intel_80286_pdr.sby`)
runs after the cover and has no recent terminal result either.

### 2. Real historical software on the RTL

- OS/2 SDK 1.00 `CPGREP.EXE` runs only in PCjs (report
  `2026-10-27-os2-cpgrep-pcjs-replay.md`); there is no RTL execution or
  independent trace. This is milestone 5 of the implementation plan.
- The DOS boot in the system is not compared with an independent model.
  Adding a Unicorn or PCE replay of the DOS run's real-mode instructions
  would make it oracle evidence, not only a screen check.
- The system goal after DOS is Microsoft OS/2 1.0, which needs the fixed
  disk (system issue #254) and exercises protected mode for real.

### 3. ISA and protected-mode gaps

From `plans/isa_inventory.md` and the completion ledger; each needs
Intel 210498-005 citations and an independent oracle:

- ESC memory forms and D9–DF execution; connect the standalone
  processor-extension data channel (PEREQ/PEACK#) to the CPU and native bus;
  automatic LOCK; real 80287 software. Assumption A25 (WAIT saved IP) is open.
- SCAS fault state and restart outside the focused string cases.
- Complete LOCK prefix legality and automatic descriptor-table locks.
- Protected-mode invalid-opcode inventory, #UD with invalid IDT/stack, and
  priority/escalation.
- Remaining #DF classification and direct task-transfer fault priorities.
- 7,490 F6/F7 memory records in the physical capture set are not replayed by
  the adapter.
- Remaining CPL1/CPL2 exception and external-vector transitions.

### 4. Assumptions that need silicon or a second source

A47 (near transfers beyond the CS limit, settled with PCE-286 only), A48
(interrupt shadows across WAIT, an owner choice), A31 (Appendix B versus the
manual's own contradiction). See `spec/spec.md`. Do not close these from an
emulator alone; record the evidence source.

### 5. PCE-286 waivers

93 differences are waived in `tb/pce_oracle/waivers.json`, each with a
citation. Re-check them when the RTL changes; the loop is described in
`plans/pce_oracle_loop.md`. Four were added for #284 finding 3 because
PCE-286 applies the 386 #TS rule.

### 6. Native pins and board-level behaviour

Board clock generation and physical phase/reset timing, MULTIBUS mode,
80287 pins, automatic coprocessor locks. The native wrapper is digital only.
