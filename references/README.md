# Shared manufacturer references

[1981_Intel_Peripheral_Design_Handbook.pdf](1981_Intel_Peripheral_Design_Handbook.pdf)
is Intel's 1981 *Peripheral Design Handbook*, saved for this project's Intel
peripheral recreations. Source:
[Bitsavers mirror](https://bitsavers.trailing-edge.com/components/intel/_dataBooks/1981_Intel_Peripheral_Design_Handbook.pdf).
The original manufacturer material and notices are retained. Chip-specific
reference notes remain in each `design/<chip>/references/README.md`.

The PDF has 908 pages and is 65,164,894 bytes. SHA-256:
`90b0d961f0e324944d07b3cedef31b8133ef9f49cf8b3d60d4469ddc533becec`.

[Intel MCS-8 Users Manual (8008), November 1973](intel_mcs8_users_manual_nov1973.pdf),
the original Intel scan used by the intel_8008 design (a searchable Markdown
transcription stays in `design/intel_8008/references/`). Source:
[DeRamp's Intel archive](https://deramp.com/downloads/mfe_archive/050-Component%20Specifications/Intel/Microprocessors%20and%20Support/8008%20Family/i8008UM%20Nov%2073.pdf).
The PDF is 4,061,851 bytes. SHA-256:
`e2b576af238be02755adf046af5443a47b168b385a87bae606149ce217860f84`.

[Intel 3205/3404 combined data sheet](intel_3205_3404_datasheet.pdf),
the primary functional contract for the intel_3205 and intel_3404 designs
(catalog pages 2-35 to 2-38: 3205 1-of-8 decoder, 3404 6-bit latch). The
sheet itself carries no print date. Source:
[Trinity College Dublin SCSS hardware archive](https://treasures.scss.tcd.ie/hardware/TCD-SCSS-T.20250922.001/Intel-C3000-datasheets/Intel-3205-3404-datasheet.pdf).

`4dc74bd9c5909ae6e3b15d094a7e0700a87e97fd195c1a5f59fe7f315cc0cdae`.
