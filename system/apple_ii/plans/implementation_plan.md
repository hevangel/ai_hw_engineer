# Apple II integration plan

1. Complete and verify the 6502 instruction and bus behavior against independent sources.
2. Expand the initial RAM/ROM/keyboard decoder to cover original motherboard I/O and display soft switches; the current RAM and keyboard block has a focused regression.
3. Add text video timing and row addressing, then graphics and speaker/cassette behavior.
4. Boot an authentic Apple II Monitor/Integer BASIC ROM with a reproducible, licensed or user-supplied image. Check an externally sourced execution trace and visible monitor behavior.
5. Add optional expansion devices after the base machine passes.
