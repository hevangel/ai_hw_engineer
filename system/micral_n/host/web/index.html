About this machine

The panel follows R2E's January 1974 manual: AUTO, instruction or cycle step, trap, substitution switches, and address/data lamps. The processor and memory transactions are simulated by Verilator.

The default program is MO5's public Micral N I/O exercise. It waits for bit D7 on input group 5, then sends incrementing values to an output port. It is a demonstration image; the original MIC-01 ROM is not included.
