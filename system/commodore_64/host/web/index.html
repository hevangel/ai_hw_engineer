Commodore 1982. MOS 6510 CPU, MOS 6569/6567 VIC-II, MOS 6581 SID, two MOS 6526 CIAs and the 906114-01 PLA, all from this repository's RTL, running the original BASIC, KERNAL and character ROMs fetched and hash-checked at run time. The SID analog filter, cartridges, the 1541 drive and the tape port are outside the model; colors use the Pepto palette.
