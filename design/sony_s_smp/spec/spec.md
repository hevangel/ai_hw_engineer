# Specification: Sony S-SMP

## 1. Overview

The S-SMP wraps the project's [SPC700 core](../../sony_spc700/) with the
memory map, I/O registers, timers and boot ROM of the SNES sound module.
Sources: [fullsnes "SNES APU"](https://problemkaputt.de/fullsnes.htm) and the
[SNESdev wiki S-SMP page](https://snes.nesdev.org/wiki/S-SMP).

## 2. Features

- One SPC700 bus cycle per `ce` (1.024 MHz, generated by the board from the
  master clock with a phase accumulator).
- Memory map: 64 KB audio RAM through the S-DSP; registers at $F0-$FF; the
  64-byte IPL ROM at $FFC0-$FFFF when CONTROL bit 7 is set.
- Registers: TEST ($F0, including the timer and RAM-disable bits), CONTROL
  ($F1: timer enables, port clears, ROM enable), DSPADDR/DSPDATA ($F2/$F3),
  four CPU ports ($F4-$F7, separate in and out latches), AUXIO ($F8/$F9),
  timer targets ($FA-$FC) and 4-bit up-counters ($FD-$FF, cleared on read).
- Timers: stage 1 divides the cycle counter (T0 and T1 every 128 cycles,
  T2 every 16), stage 2 compares with the target, stage 3 is the 4-bit
  output counter. Enabling a timer resets its stages 2 and 3.
- Writes to $F0-$FF also reach the RAM underneath.

## 3. Interfaces

| Port | Dir | Width | Description |
|------|-----|-------|-------------|
| `clk`, `rst_n`, `ce` | in | 1 | Master clock, reset, SPC700 cycle enable |
| `cpu_addr`, `cpu_wr`, `cpu_wdata`, `cpu_rdata` | | 2,1,8,8 | 5A22 side of the ports ($2140-$2143) |
| `dsp_addr`, `dsp_wr`, `dsp_wdata`, `dsp_rdata` | | 7,1,8,8 | S-DSP register window |
| `mem_addr`, `mem_wr`, `mem_wdata`, `mem_rdata` | | 16,1,8,8 | Audio RAM access through the S-DSP |
| `ipl_we`, `ipl_addr`, `ipl_data` | in | 1,6,8 | IPL ROM load by the host |
| `pc_o`, `fetch_o` | out | 16,1 | Debug |

## 4. Assumption ledger

| # | Assumption | Reason / evidence |
|---|------------|-------------------|
| A1 | TEST wait-state fields are stored but every access takes one cycle. | Software runs with the default setting; wait states only slow the core. |
| A2 | A timer's stages 2 and 3 reset on the rising edge of its CONTROL enable bit, for all three timers. | fullsnes. The ares source tests the opposite edge for timer 2 only, which looks like a typo. |
| A3 | With RAM reads disabled by TEST, reads return $5A. | Documented hardware observation (fullsnes). |
| A4 | The IPL ROM image comes from a pinned copy of the snes9x source (`scripts/fetch_ipl.py`, sha256 checked). | The ROM is copyrighted and kept in `work/`. |
