# Motorola MC68000 (work in progress)

The MC68000 (1979) is Motorola's 16-bit processor: sixteen 32-bit
registers, a 24-bit address space, user/supervisor separation, fourteen
addressing modes, and exception processing that founded the 68k family
line (68020/30/40, ColdFire). It powered the original Macintosh, the
Amiga, the Atari ST, early Unix workstations, and countless embedded
controllers.

Motorola announced the MC68000 in **1979** (September announcement is the
commonly cited date; the exact day is not asserted here). Behavior is
verified against the [SingleStepTests 680x0
suite](https://github.com/SingleStepTests/680x0) — 1,000,060
single-instruction vectors with full processor and memory state before
and after, generated by an implementation that "conforms to all available
documentation, official and third-party; passes all other published test
sets; and has been verified by usage in an emulated machine."

## Status: work in progress

Following the repo's intel_80286 pattern, this design lands in verified
increments:

- **complete**: verification harness (all 1,000,060 vectors compiled to
  `work/sim/m68k_*.bin` by `scripts/make_68000_vectors.py`), RTL
  skeleton (`src/motorola_68000.sv`: register file, USP/SSP banking,
  fetch/retire handshake — lint and synthesis clean), and the suite
  fetcher (`scripts/fetch_vectors.py`; the ~194 MB vector download is
  working-tree only, not committed).
- **next**: MOVE group first (all 14 addressing modes), then the ALU,
  MUL/DIV, shifts, flow, and exception classes — each closing against
  its slice of the vectors.

See `spec/spec.md`, `plans/implementation_plan.md`, and
`report/final_report.md` for the contract, landing order, and status.
