# Independent reference provenance

Instruction vectors: [SingleStepTests/8086](https://github.com/SingleStepTests/8086), immutable commit `e71c68d215a6bb8c356bd4cb3842de3bef345ca9`, `v1/*.json.gz` and `v1/metadata.json`. Daniel Balsom generated these using ArduinoX86/MartyPC and a physical Intel P80C86A-2. The upstream repository is MIT licensed. Fetching retains its license and README in ignored `work/reference/`.

The downloader verifies each downloaded object against its Git blob SHA from the pinned Git tree before caching or converting it. The tree and source commit are retained beside the data. The converter does not implement an instruction interpreter: expected registers and RAM are copied from physical-chip results. Its ordered write oracle expands physical bus traces into bytes using ALE, BHE and the write-active T3 data, as documented in the upstream README's cycle format. Undefined flags use upstream metadata; unsupported encodings and prefetch-incompatible cases are excluded explicitly. This fixture selection is narrower than the complete hardware corpus.

Intel technical source: *8086 Family User's Manual*, October 1979, document 9800722-03, chapter 2, especially programming model, effective-address tables, instruction descriptions and figure 2-63. [Readable scan](https://www.inf.pucrs.br/~calazans/undergrad/orgcomp_EC/mat_microproc/intel-8086_family_Users_Manual.pdf), [Bitsavers archive](https://bitsavers.org/components/intel/8086/9800722-03_The_8086_Family_Users_Manual_Oct79.pdf). Manufacturer documents are linked, not redistributed in the design.
