# Test plan

Verify all 15 opcodes plus invalid encodings, command/result byte counts, RQM/DIO/NDM/CB, held strobes, DACK before RD/WR, ND byte interrupts and result IRQ acknowledgement. Use deterministic sector contents independent of command parameters. Exercise read/write/deleted/skip, multi-sector/head transfers, TC partial read/write with CRC drain/zero fill, Table 8 result IDs, Read ID, Read Track index gating, nonsequential formatting IDs/filler/CRC, scan equality/order/FF masks/STP, wrong cylinder, missing marks, ID/data CRC errors, EOT/no-TC, overruns, not-ready/write-protect/fault. Check parallel seek pulse count/direction/PCN, SIS ordering and drain, recalibrate success/77-step failure, ready polling and head timers. Sweep lengths N=0–6 and seeded bytes/stalls.

Independent codec vectors cover all 256 FM/MFM bytes with both previous-bit values, missing-clock A1/C2/FM address marks, and CRC known-answer/residue tests. CPU-facing UVM includes sequences, protocol driver, passive monitor, scoreboard and a dedicated coverage collector. Formal covers all useful command/control phases; raw flux and real operating-system drivers are outside the boundary stated in the spec.
