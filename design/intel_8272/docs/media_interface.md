# Decoded-media integration

All inputs are synchronous to `clk`; assert `rst_n=0` for at least one rising edge. Drive active-low host strobes high between transfers. Hold command and result transfers until MSR.RQM and the appropriate DIO direction; a held strobe transfers only once. DMA uses DACK and a separate RD/WR edge, with CS inactive permitted. DACK alone drops DRQ and reserves the pending byte. Non-DMA uses the data port and asserts IRQ per pending byte. The first result read acknowledges completion IRQ; status reads do not.

`unit`, `head`, `mfm`, `head_load`, `direction[3:0]` and `step[3:0]` expose logical drive control. Ready, protection, track-zero, two-sided and fault inputs are per-drive vectors. A step is one clock pulse, separated by Specify's SRT timer. Provide `us_tick` at one pulse per emulated microsecond. The default `MS_US=1000` maps milliseconds to 1000 ticks; reduced values accelerate seek/head timers for verification only.

When `media_active` asserts, select the actual recorded track using the physical cylinder maintained by the backend and the core's selected unit/head. Do not generate a header by copying the requested `sector_c/h/r/n`: that would hide wrong-cylinder and missing-ID errors. Pulse `index_pulse` once per revolution and `header_valid` for each encountered header. Supply its recorded C/H/R/N, deleted mark, missing-data indication and ID CRC error. The core searches for ordinary data commands; Read ID accepts the first header; Read Track waits for index and consumes encountered sectors in order.

After an accepted header for reading/scanning, pulse `media_byte_valid` with each actual byte. The core has one byte of buffering. Service the host before another byte arrives, and within 13 ticks in MFM or 27 in FM; violation sets overrun. Pulse `media_end` after the physical sector, with `media_crc_error` for the full field. This event may coincide with the last byte. TC ends read host transfers but the backend must continue bytes/CRC through `media_end`. Scan TC enters result after the last accepted comparison, so stop scan delivery when `media_active` drops.

For writes, `sector_begin` publishes the current metadata and mark selection. The controller requests host data. Allow host service before asserting `write_slot`; the deadline is 15 MFM or 31 FM ticks. Each slot produces `tx_valid/tx_byte` on the following registered outputs. `sector_end` accompanies the last byte. TC's already accepted byte is retained; subsequent bytes are zero-filled. The backend encodes marks, bytes, CRC and gaps, and updates the disk image. Do not assert slots after sector-end until a new sector begins.

Format waits for index, requests four CHRN bytes per programmed sector, and emits `sector_begin` with those supplied IDs. Supply slots for the command's sector size; the core emits filler D and sector-end. SC controls the number of sectors. After the final sector, a trailing index completes the command. Format result CHRN is not defined by Intel; this model exposes the last supplied ID with R+1 for reproducibility. SC=0 exposes command-derived placeholder IDs. TC during ID collection aborts with the partial current IDs; do not commit a partial sector to the image. TC during search or index/head-load wait also aborts immediately.

`intel_8272_codec` encodes/decodes one 16-bit word. Supply the prior data bit for MFM normal encoding. Mark 0 is normal, 1 is MFM A1 (4489), 2 MFM C2 (5224), 3 FM C7-clock mark. `next_data` chains word encoding; `missing_clock` recognizes MFM sync words or non-FF FM clocks. `intel_8272_crc` starts at FFFF, updates on each `byte_valid`, and clears synchronously. For MFM sector fields include A1/A1/A1 and the field mark; FM starts at the field mark. Append CRC high byte then low byte; a valid field has zero residue. These helpers do not implement the backend's track state machine.
