# Reference provenance

Intel's [8272A preliminary datasheet](https://www.threedee.com/jcm/terak/docs/Intel%208272A%20Floppy%20Controller.pdf), order 210806-001, AFN-01259C, ©1982, is preserved as [intel_8272a.pdf](intel_8272a.pdf). [Searchable extraction](datasheet_extract.txt) assists navigation; the scanned command/status tables on PDF pages 8, 10, 11 and 12 were visually inspected. The specification paraphrases behavior and retains conflicting or undocumented cases in an assumption ledger.

Other manufacturer references: [NEC µPD765A datasheet](https://hxc2001.com/download/datasheet/floppy/thirdparty/FDC/NEC/upd765A.pdf) for compatible scan FF masking; [Dilog DQ419 manual](https://www.bitsavers.org/pdf/dilog/DQ419/DQ419_198503.pdf) for IBM CRC polynomial and clock/data formatting; [CCS 2422 controller manual](https://www.hartetechnologies.com/manuals/CCS/CCS_2422_Floppy_Controller_Manual.pdf) for IBM field layout. [MAME's µPD765 implementation](https://github.com/mamedev/mame/blob/master/src/devices/machine/upd765.cpp) corroborates event latches and recalibration direction. Intel determines scan comparison direction and Table 8 result IDs; the RTL is not a translation of that emulator.

[greaseweazle_ibm.py](greaseweazle_ibm.py) retains the first 93 lines of [Keir Fraser's public-domain IBM codec](https://github.com/keirf/greaseweazle/blob/master/src/greaseweazle/codec/ibm/ibm.py), including the upstream license notice. It was retrieved on October 2, 2026. Only AST-extracted upstream encoder functions run in [generate_vectors.py](../scripts/generate_vectors.py). No RTL is imported or read. The script generates [codec_vectors.hex](codec_vectors.hex) for all 256 byte values, both preceding bits and both densities; Python's standard `binascii.crc_hqx` independently establishes CRC known answers and residue. Generate vectors with `python3 design/intel_8272/scripts/generate_vectors.py`.

The 123456789 CRC is 29B1. The MFM ID field A1 A1 A1 FE 03 00 01 02 has CRC 51B3. Missing-clock words 4489/5224 and FM FE word F57E are checked separately from normal encoding. All result/status expectations in the host tests are fixed manufacturer-table values; media content is generated independently of requested CHRN and compared byte by byte.
