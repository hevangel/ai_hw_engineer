# AMD Am9518 Data Ciphering Processor

The Am9518 is AMD's NBS/DES data ciphering processor: a peripheral that
encrypts and decrypts 64-bit blocks with the National Bureau of Standards
Data Encryption Standard through Electronic Code Book, Cipher Block Chain
and 8-bit Cipher Feedback modes. Three separate ports — master data, slave
data and key — allow overlapped input, output and ciphering, with separate
E/D/master key registers, initializing-vector registers and per-byte odd
parity checking of key material. It was designed to hang directly on the
AmZ8000 bus and, with a little glue logic, on the 2900, 8080, 8085, 8086
and 8051 families.

First introduced: **1980**. AMD's 1980 Am9500 Peripheral Products Interface
Guide (bitsavers) carries a two-page preliminary Am9518 datasheet; the final
Am9518/AmZ8068 datasheet (doc 00618B, printed pages 2-461…2-478) pairs it
with the faster AmZ8068 in AMD's MOS Microprocessors and Peripherals
databook. No exact launch month is asserted.

This reconstruction implements the full documented functional contract:
all 23 command codes, multiplexed- and direct-control master-port modes,
the auxiliary key port with AFLG/ASTB handshake, the slave data port with
the datasheet's Figure 6 flag association, ECB/CBC/8-bit CFB ciphering in
both directions, clear and encrypted key/IV loads, IV readback (clear and
encrypted), Encrypt-with-Master-Key, hardware/software/abort resets with
the five-clock command blackout, and the documented pipeline timing
(8 clocks per block in, 18-clock algorithm window, 8 clocks out).

Verification is anchored on an independent oracle: every test vector was
generated by third-party `pyDes` and cross-checked bit-for-bit against
OpenSSL's legacy DES, plus AMD's own published 8086 interface-test vector
(key 8000000000000000, plaintext 0000000000000000 → cipher text
95A8D72813DAA94D, reproduced exactly, which validates byte order, LSB
parity handling and the algorithm together).

  PDF pages 32–33 and 134–135 (preliminary datasheet, 1980 date evidence).

  (Z80 interface), 141 (8085 interface).

Run `sh design/amd_am9518/scripts/run_all.sh` inside the repository
toolchain container: lint (verilator -Wall), formal (SymbiYosys bmc/prove/
cover), the ten simulation suites (Verilator, 1300+ checks), and Yosys
synthesis. `scripts/generate_vectors.py` regenerates the pinned vector
files (requires `uv run --with pyDes`) and re-verifies the published
anchors. Nanosecond AC parameters and the Am9568 interface variant are
outside the documented functional contract; see the assumption ledger.
