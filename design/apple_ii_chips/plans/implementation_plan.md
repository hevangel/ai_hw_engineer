# Implementation plan

1. Preserve physical pin identities, source provenance, and corrections.
2. Implement individual TTL packages, memory packages, and bus drivers.
3. Test truth tables, sequential control priority, X propagation, and Z buses.
4. Instantiate packages at motherboard locations from audited connectivity.
5. Add explicit analog boundaries and validate timing against schematics.
6. Connect a complete NMOS 6502 and boot historical Apple firmware.
7. Keep the system acceptance gate failing until all requirements pass.
