# 74x923: 20-key encoder

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [National Semiconductor MM54C922/MM74C922 16-key
encoder, MM54C923/MM74C923 20-key encoder, 1977 National CMOS
Databook](https://bitsavers.org/components/national/_dataBooks/1977_National_CMOS_Databook.pdf),
printed pages 1-136 to 1-139, PDF pages 151-154 (one-based), shared with the
MM74C922. SHA-256:
`3e8c5ec749791505ac253578b0a12aeb0411f7f33272dfb8df35bd7f5e684227`.
Connection diagrams on PDF page 151; switching-time waveforms (Figure 1
debounce/rollover, Figure 2 output-enable) on PDF page 153; block diagram and
full 20-position truth table on PDF page 154. The same combined datasheet
with additional application pages appears in the [1981 National CMOS
Databook](https://bitsavers.org/components/national/_dataBooks/1981_Natonal_CMOS_Databook.pdf)
(SHA-256 `7330b1a886d14e2c9037679942d911972219990be182661f786f633bad457ae6`,
PDF pages 179-185), visually reviewed for consistency.
**Status:** implemented.

The MM74C923 is the MM74C922 extended to a 4x5 matrix: a fifth row sense Y5
and a fifth data output E, the most significant row bit, give twenty key
positions. Everything else — column scan, KBM debounce, DATA AVAILABLE
handshake, two-key rollover, last-key register, Output Enable tristate —
matches the MM74C922; see [74x922](ttl_74x922.md) for the shared native
digital contract, which this model implements identically.

## Device-specific contract

`row[4:0]` observes Y1-Y5 (pins 1-5, Y1 in bit 0). `data[4:0]` is DATA OUT
{E,D,C,B,A} (pins 15-19; A least significant in bit 0, E most significant).
Per the truth table (PDF page 154), a key at row r (Y1=0..Y5=4), column c
(X1=0..X4=3) latches {E,D,C,B,A} = {r[2],r[1],r[0],c[1],c[0]} — column code
on B,A; row code on E,D,C. All twenty switch positions 0-19 are covered by
the table; positions 16-19 (row Y5) assert E and are the positions the
16-key MM74C922 does not have.

ASSUMPTION: Same oscillator/KB M normalization, scan order, power-up and
multi-key notes as the 74x922 specification. The E output ("*Omit for
MM54C922/MM74C922" in the truth table) simply does not exist on the 922; on
the 923 it is an ordinary last-key-register bit behind Output Enable.
Analog drive levels, thresholds and timings are omitted.
