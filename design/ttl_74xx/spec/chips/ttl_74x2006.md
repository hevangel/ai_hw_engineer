# SN74GTL2006: 13-bit GTL/GTL+ to LVTTL translator

**Historical date:** TI datasheet SCES619 is dated December 2004; the product's exact first-introduction date is not established here.
**Manufacturer source:** [TI SN74GTL2006 datasheet](https://www.ti.com/lit/gpn/sn74gtl2006), function tables p. 2 and logic symbol p. 3.
**Status:** implemented as a digital logic model.

## Function

This model represents the pin logic at valid supply and reference levels. Vector bit 0 corresponds to channel 1 (or pin suffix 1), then suffixes increase with bit index. A `_drive_low` output means an open-drain output is sinking low; zero means it is released. LVTTL OD pads are resolved as `drive_low ? 0 : external_drive ? external_data : 1`. An external high while the chip sinks resolves low in this ideal wired-AND abstraction; analog contention current is out of scope. GTL input bits are already classified against the configured VREF.

- `ao_1_2_3_4 = bi_1_2_3_4`; `ao_9 = bi_9` (push-pull LVTTL outputs).
- `bo_8_drive_low = !ai_8`.
- `bo_10_drive_low[i] = !(ai_10[i] & bi_9)` for the two independent `10AI1/2` channels.
- For channels 5 and 6, `a_5_6_drive_low[i] = !bi_5_6[i]`. The resolved LVTTL bus feeds the GTL return function: `bo_7_drive_low[i] = bi_5_6[i] & !a_5_6_bus[i]` (equivalently, the logical 7BO value is `!BI | A_bus`).
- `a_11_drive_low = bi_11`; `bo_11_drive_low = a_11_bus` (the logical 11BO value is the complement of the resolved 11A level).

The 7BO channels include an analog delay in the source datasheet to suppress a transient glitch; this zero-delay model implements the stable-state function table only.

## Scope assumptions

Power-up behavior, VCC/VREF analog thresholds, output drive strength, propagation delay, bus termination, and contention currents are not modeled. Unconnected open-drain buses resolve to high through the modeled pull-up assumption. Source page pin descriptions classify the 28-pin package pins; this module omits supply pins.
