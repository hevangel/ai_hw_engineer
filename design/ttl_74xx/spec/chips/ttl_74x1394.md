# SN74GTLP1394: 2-bit GTLP/LVTTL transceiver with feedback and polarity control

**Historical date:** TI datasheet SCES286F is dated October 1999, revised April 2005; the exact product introduction date is not established here.
**Manufacturer source:** [TI SN74GTLP1394 datasheet](https://www.ti.com/lit/gpn/sn74gtlp1394), functional description, control and ERC tables, and logic diagram p. 3.
**Status:** implemented as a digital logic model.

## Function

Two lanes use bit 0 for channel 1 and bit 1 for channel 2. `tc=1` is true transmission; `tc=0` complements data in both directions. `oeab_n=0` enables the B-port output; `oeby_n=0` enables the separate LVTTL Y feedback output. The model exposes B and Y data separately from their active-high output enables: `b_output_data = tc ? a_in : ~a_in`, and `y_output_data = tc ? b_bus_in : ~b_bus_in`. `b_bus_in` is the externally resolved GTLP bus sample used by the Y path, including any active device drive. When the corresponding enable is high, the output is high impedance regardless of its data value.

The output-control table is: both enables inactive gives isolation; B only transfers A→B; Y only transfers B→Y; both active provide the feedback path. `ERC=1` selects fast B-port edges and `ERC=0` slow edges.

## Scope assumptions

Digital data, polarity, enable, and edge-rate mode are represented; analog GTLP swing, VREF thresholding, edge shape, propagation, power-up 3-state behavior, live insertion, and drive strength are excluded. B bus levels are input as already-resolved logic values. Package supply, VREF, BIAS VCC, and GND pins are not module ports.
