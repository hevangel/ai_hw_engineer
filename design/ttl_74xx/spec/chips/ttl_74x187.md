# ttl_74x187 — 1024-bit ROM (256x4)

256-word x 4-bit mask-programmable ROM.


## Read-only implementation correction

The model is a 256×4 read-only memory with **no runtime write port**. `INIT_FILE` selects its mask/fuse image. `DEFAULT_WORD` defines an explicit blank image when no image is supplied; no historical mask or erased-fuse polarity is implied. The test image is synthetic address-decoder data, not historical content. The imported writable-memory description above is superseded.
