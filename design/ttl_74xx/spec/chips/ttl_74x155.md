## Functional baseline and interface notes

# ttl_74x155 — Dual 2-to-4 decoder with shared address

Two 2-to-4 decoders sharing the same address. Per-decoder active-low
enable. Each decoder's outputs (`y0_n`, `y1_n`) are active low.


## Demultiplexer data pins

The two `c` data controls are retained: section 0 enables on C high, section 1 enables on C low. Each also requires its active-low `g_n`. TI SN74LS155A/SN74LS156 function tables define the opposite C polarities.
