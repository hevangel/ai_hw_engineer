## Functional baseline and interface notes

# ttl_74x292 — Programmable frequency divider / digital timer

Divides clock by 2^`div_sel`. Output `q` toggles each time the internal
counter reaches the divisor.


## Reviewed digital contract

Programming code n selects division by 2**n; codes 0/1 inhibit. The 292 supports n up to 31. The normalized `clk` represents the OR-gated native CLK1/CLK2 clock. Test-point pins and live mode-change ripple transients are not exported. Clear when changing the divisor. TI SDLS153A (January 1981) pins these ratios; the baseline had a factor-of-two error.
