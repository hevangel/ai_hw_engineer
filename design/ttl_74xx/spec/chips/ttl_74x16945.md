# 74x16945: 16-bit LVTTL-to-GTLP bus transceiver

**Manufacturer source:** Texas Instruments SN74GTLPH16945, SCES292C (October 1999, revised September 2001), in the official [TI GTLP design guide SCED004A](https://www.ti.com/lit/ug/sced004a/sced004a.pdf), printed pages 3-245 to 3-256; the package pinout is on book PDF page 301, and the description and function table on PDF page 303. Book PDF SHA-256: `414fb09c44deff6897c9fdf90ea9b59f9f592e5f78067cb4d65d80018799a995`.

A 50 mA high-drive 16-bit bus transceiver partitioned as two independent 8-bit
segments for asynchronous LVTTL-to-GTLP data-bus communication. Data polarity
is noninverting. Except for the 50 mA drive class and the absence of the ERC
edge-rate pin this is the same contract as the SN74GTLPH1645.

## Logical contract

Section 1 maps package 1A1..1A8/1B1..1B8 to vector bits [7:0] with controls
`oe1`/`dir1`; section 2 maps 2A1..2A8/2B1..2B8 to bits [15:8] with `oe2`/`dir2`.
The A port is LVTTL (push-pull); the B port is GTLP and sinks only — the source
lists 100 mA low-state B-port output current and no B-port high-state drive, so
the B high level comes from board termination. `b_in` observes the resolved B
bus including the termination pullups.

Per the function table (identical for both sections):

| OE | DIR | Output | Mode |
|---|---|---|---|
| 1 | X | released | Isolation |
| 0 | 0 | `a_out = b_in` | B data to A port |
| 0 | 1 | B bus sinks A data | A data to B port |

OE is the native pin polarity: high isolates, low enables. DIR high transfers
A to B; DIR low transfers B to A. Both sections operate completely
independently, including opposite directions at the same time.

VREF and BIAS VCC are analog references and are omitted from this
pure-digital contract; this device has no ERC edge-rate pin.

ASSUMPTION: Inputs are valid resolved digital levels on a powered device with
settled controls. `b_drive` is an explicit low-only sink indication; board
models must supply termination pullups, resolve the bus, and only then feed
`b_in`. Masked outputs are zero and ignored by board adapters. There is no
invented storage, reset or clock.
