# 74x477: 4096-bit PROM (1024x4)

First introduced: Unknown; exact launch date has not been established.
Manufacturer source: [SN74S477](https://archive.org/details/bitsavers_tidataBookcomputerComponentsDataBook_16851665/page/n177).

## Read-only normalized contract

1024 words of 4 bits. `addr` selects the word asynchronously.
`cs_n=0` drives `data_out`; `drive=1` means selected. Disabled data is zero
and must be ignored. `INIT_FILE` loads a hexadecimal mask image; absent images
default to erased all-ones words. No write pins exist. Field programming voltages,
power-down timing and programming pulses are outside the digital read contract.
ASSUMPTION: The normalized interface uses positive data polarity; native package
enable combinations must be mapped at the board boundary. This is not a historical
mask image or native programming-pin replica.

The part is a programmable/read-only storage building block used for board-level
lookup and control logic. Its historical mask must be supplied by the caller.
