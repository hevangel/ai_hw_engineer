## Functional baseline and interface notes

# ttl_74x279 — Quad S-R latch

Four NAND-style S-R latches (active-low inputs). `s_n=0, r_n=1` sets Q;
`s_n=1, r_n=0` resets Q. Both inputs low is the "illegal" state on the
real chip; this RTL holds the previous value.


## Native set controls

Sections 0 and 2 have secondary active-low set inputs `s2_n`. Tie these high when unused. While set and reset are both low the NAND latch Q is forced high; simultaneous release is not a valid initialization method.
