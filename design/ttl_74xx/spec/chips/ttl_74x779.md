# 74x779: 8-bit bidirectional binary counter with three-state I/O

**First introduced:** Unknown; April 1988 is the Fairchild data-sheet date, not a confirmed introduction year.
**Manufacturer reference:** [Fairchild 74F779 data sheet, DS009593](https://mm.digikey.com/Volume0/opasdata/d220001/medias/docus/966/74F779.pdf).
**Status:** implementation-ready digital model.

The Fairchild sheet identifies a synchronous 8-stage up/down counter with multiplexed three-state I/O and carry lookahead. All state changes occur on the rising edge of `CP`. It has no reset input. The function table and the clock/enable descriptions on data-sheet page 2 specify the following controls (`H` and `L` mean logic high and low):

| S1:S0 | CET | OE | CP | Action |
|---|---:|---:|---|---|
| X:X | X | H | X | I/O pins high impedance |
| X:X | X | L | X | Counter contents drive I/O pins |
| L:L | X | H | rising edge | Load all eight flip-flops from the I/O pins |
| Not both low | H | X | rising edge | Hold count; TC held high |
| H:L | L | X | rising edge | Count up |
| L:H | L | X | rising edge | Count down |

`OE` and `CET` are active low. `S1:S0 = 00` selects the synchronous parallel load, `10` selects up count, and `01` selects down count. The I/O pins are input data during load and output data when `OE` is low. The model accepts separate external data and drive-mask inputs, then reports the counter’s drive mask and resolved bus state so tests can cover loading, high impedance, and external-driver conflicts without using a simulator-specific `inout` net.

`TC_n` is an active-low terminal-count output. The manufacturer’s IEEE/IEC symbol on page 1 identifies the two terminal conditions as count 256 for the up direction and count 0 for the down direction; the model reports the active-low level at `FF` while counting up and at `00` while counting down, with `CET_n` low. It holds high when counting is disabled. The data sheet warns that TC can contain decode spikes and should not serve as a clock or asynchronous reset; this digital model represents its stable Boolean terminal condition and omits propagation delays and decode hazards.

**ASSUMPTION:** `S1:S0 = 11` with `CET_n = L` is absent from the published function table; the model holds the count and leaves TC inactive for that unlisted combination. `S1:S0 = 00` with `OE_n = L` is also unlisted; the model holds the count because the specified load row requires `OE_n = H`. The split-bus interface treats external drive masks as ideal strong drivers. Floating inputs and electrical contention are reported with `io_bus_valid` and `io_bus_conflict`; analog voltage and strength resolution are outside scope. A load is meaningful when the board supplies defined values on all I/O pins.

The complete logical function table and pin interpretation are from Fairchild DS009593 pages 1–3. Page 1 states rising-edge operation, gives the logic symbol and pinout; page 2 gives the I/O load table and function table; page 3 gives the logic diagram. Analog timing and electrical limits are excluded.
