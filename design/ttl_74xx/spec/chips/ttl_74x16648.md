## Logical contract

The device has two independent 8-bit sections: section 1 uses bits 7:0 and section 2 uses bits 15:8. Each section has independent active-low output enable `oe_n`, direction `dir`, positive-edge clocks `clkab` and `clkba`, and select controls `sab` and `sba`. The source pinout numbers these controls separately as `1OE`, `1DIR`, `1CLKAB`, `1CLKBA`, `1SAB`, `1SBA` and corresponding section-2 pins.

- `oe_n=0` enables the selected output direction; `oe_n=1` isolates outputs.
- `dir=0` selects B-to-A transfer; `dir=1` selects A-to-B transfer.
- A rising edge of `clkab` stores the A-side input in its section register. A rising edge of `clkba` stores the B-side input. Input capture remains enabled regardless of OE and DIR.
- For B-to-A transfer, `sba=0` selects real-time B input; `sba=1` selects the stored B register, and the function table specifies that stored transfer with `clkba=0`.
- For A-to-B transfer, `sab=0` selects real-time A input; `sab=1` selects the stored A register, and the function table specifies that stored transfer with `clkab=0`.
- The manufacturer describes an inverting data path. Both real-time transfers and stored-register transfers therefore produce the complement of the selected source data.

The logical interface uses `a_in[15:0]`, `b_in[15:0]`, `a_out[15:0]`, and `b_out[15:0]), with per-section `a_drive[1:0]` and `b_drive[1:0]` flags. Only the output side selected by each section's DIR may be driven. Drive flags are asserted only for function-table output modes; undriven data outputs are masked to zero and ignored. The source does not specify output behavior for combinations absent from its function table, so those combinations are outside the conformance contract and are modeled as not driving. Register power-up contents are unspecified; no reset or initialization is added.

The model preserves the specified edge capture, clock-level condition for stored-data transfer, inversion, independent section controls, and high-impedance output behavior. Timing, analog/electrical behavior, and family-specific drive characteristics are omitted.
