It provides a single ten-bit bidirectional path controlled by a dual-polarity enable condition. This model preserves the source's digital connectivity controls and bidirectional paths. It is a passive switch network, not a directed Boolean mux.

## Controls and topology

The device has one active-high OE input and one active-low OE_n input. The ten bidirectional paths conduct only for OE=1 and OE_n=0.

| OE (pin 1) | OE_n (pin 23) | Function |
|---:|---:|---|
| 0 | 0 | Disconnect |
| 0 | 1 | Disconnect |
| 1 | 0 | A port = B port |
| 1 | 1 | Disconnect |

Port mapping: Port 0 is A1–A10 and port 1 is B1–B10; lane k is flattened bit k in each port. Flattened bus offset details: A=indices 0–9; B=10–19.

## Model contract and limits

`external_data` and `external_drive` describe external strong digital drivers only; do not feed a prior resolved value back as a new source. `resolved`, `valid`, `conflict`, and `weak_drive` use the flattened port ordering above. Ports joined by enabled switch paths form one connected component in each lane. Equal strong drivers resolve normally. Opposite strong drivers set `conflict=1`, `valid=0`, and masked `resolved=0` on every member. A component with no external source is invalid; this device supplies no modeled weak pull, so `weak_drive` is always zero.

ASSUMPTION: All external values are already valid Boolean logic levels and controls are settled. The manufacturer identifies a 5-ohm A/B bidirectional switch. The digital model treats enabled lanes as ideal zero-delay connectivity and preserves the native OE/OE_n gate condition. It omits voltage limits, on-resistance, propagation effects, power-off isolation behavior, and transient dynamics. The library applies its global passive-network rule: resolve the whole connected topology once from external sources rather than cascading already-resolved outputs.
