# 74x656: octal non-inverting buffer/line driver with parity

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [Fairchild FAST Data Book (1985), 74F655/656](https://archive.org/details/bitsavers_fairchilddldFASTDataBook_29981933/page/n553), printed pages 4-510–4-511. The parity sense is cross-checked against [TI SN74F280B](https://www.ti.com/lit/ds/symlink/sn74f280b.pdf), printed page 2-1, and [NXP 74F656A Rev. 6](https://media.digikey.com/pdf/Data%20Sheets/NXP%20PDFs/74F656A.pdf), pages 4–5.
**Status:** implemented; source reviewed.

## Function

The 74F656 is an octal non-inverting buffer/line driver with an even/odd parity generator/checker. The data outputs and both parity outputs are three-state. The three active-low output enables are combined: all must be low to enable any outputs; any high disables the data and parity outputs. There is no clock or stored state.

The data vector is `I0..I7` and parity input is `PI`. The normalized ports retain those logical functions as `d_in[7:0]` and `parity_in`. `oe_n[0]`, `oe_n[1]`, and `oe_n[2]` represent `OE1_N`, `OE2_N`, and `OE3_N`. When enabled, `q_out[i] = d_in[i]`; `po` is the odd-parity sum over `{parity_in,d_in}`, and `po_n` is the even-parity sum. Thus the parity outputs are complementary, with `po=1` for an odd number of high inputs. The native PO and PO-bar pins map to the odd and even outputs respectively; see the mapping note below.

## Local model contract

The interface represents high impedance with `q_drive` and `parity_drive`; output values are zero when their drive flag is false. Both drive flags have the same value: `oe_n == 3'b000`. The model uses ideal digital values and omits electrical strength, voltage, timing, current, and loading.

**ASSUMPTION — PO mapping:** the 1985 Fairchild entry names the physical parity pins `PO` (pin 22) and PO-bar (pin 21), and identifies the parity block as an F280 function, but its parity table is not printed in the entry. The F280 truth table defines `ΣODD` and `ΣEVEN`; NXP's later 74F656A pin table maps pin 22 to `ΣO` and pin 21 to `ΣE`. This pin-compatible revision supports the normalized mapping `PO=ΣODD`, `PO-bar=ΣEVEN` used here.

The source logic diagram connects OE1_N, OE2_N, and OE3_N to one shared output-enable condition. The normalized interface preserves this all-three-low behavior rather than treating the enables as independent banks. Power-up state is not applicable because the function is combinational.
