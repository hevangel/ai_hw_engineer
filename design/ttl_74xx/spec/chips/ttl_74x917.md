# 74x917: 6-digit hex display controller and driver

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [National Semiconductor MM74C917 6-Digit Hex Display
Controller/Driver, 1984 National Logic Databook Volume 1](https://bitsavers.org/components/national/_dataBooks/1984_National_Logic_Databook_Volume_1.pdf),
printed pages 6-180 to 6-185, PDF pages 1335-1340 (one-based), shared with the
MM74C912. SHA-256:
`9d487da7c77326e8e6578fb8c7680643e400044f05d8a74ec152a56c8e3af252`.
Connection diagram and input/output control truth tables on PDF page 1335;
character font table (separate MM74C912 and MM74C917 rows), segment
identification and block diagram on PDF page 1338; write/multiplexing
waveforms and AC parameters on PDF pages 1336-1337. The MM74C917 also has a
full section in the [1981 National CMOS Databook](https://bitsavers.org/components/national/_dataBooks/1981_Natonal_CMOS_Databook.pdf)
(SHA-256 `7330b1a886d14e2c9037679942d911972219990be182661f786f633bad457ae6`,
PDF pages 873-892), visually reviewed for consistency.
**Status:** implemented.

The MM74C917 is the MM74C912 with a hexadecimal segment ROM: the four data
bits of each register address a 16-entry font covering 0-9 and A,b,C,d,E,F.
Everything else — six 5-bit registers, CE/WE write protocol with null-digit
addresses, OSE-gated self scan, SOE segment tristate, decimal-point
pass-through — matches the MM74C912; see [74x912](ttl_74x912.md) for the full
native digital contract, which this model implements identically.

## Device-specific contract

Ports and write/scan behavior are those of [74x912](ttl_74x912.md). The only
difference is the character font (PDF page 1338, MM74C917 row, segments
a,b,c,d,e,f,g in `seg` bits 0..6): 0-9 as in the 912, then 10=abcefg (A),
11=cdefg (b), 12=adef (C), 13=bcdeg (d), 14=adefg (E), 15=aefg (F). The
decimal point still bypasses the ROM.

ASSUMPTION: Same oscillator normalization, blank tick, ascending scan start
and power-up notes as the 74x912 specification. Analog drive levels,
thresholds and timings are omitted.
