## Functional baseline and interface notes

# ttl_74x88 — 256-bit ROM (32x8)

Mask-programmable ROM. Async read. `INIT_FILE` parameter supplies a
`$readmemh` file with the contents; default is all zeros.

The real chip's open-collector outputs are not modeled.


## Read-only implementation correction

The model is a 32×8 read-only memory with **no runtime write port**. `INIT_FILE` selects its mask/fuse image. `DEFAULT_WORD` defines an explicit blank image when no image is supplied; no historical mask or erased-fuse polarity is implied. The test image is synthetic address-decoder data, not historical content. The imported writable-memory description above is superseded.
