# 74x1018: analog bus-termination array

First introduced: Unknown; November 1992 documentation is not confirmed shipment.
Primary artifact: TI SN74F1018 SDFS094, page 1, [manufacturer PDF mirror](https://datasheet.datasheetarchive.com/originals/distributors/Datasheets-36/DSA-706945.pdf).
SHA-256: `1be0925db672e7b20c32e93173693d84d4eef3af215df7ab78655d10f9838818`.

The 18-line R-C network and Schottky clamp-to-ground diodes reduce bus reflection,
ringing and overshoot. The source schematic lists 50-ohm resistors and 47-pF
capacitors. It defines no digital input/output truth table or state function.

Status: Excluded under the user's pure-digital scope. Schottky diode and R-C bus-termination network; analog-only behavior outside the user-requested pure-digital scope.
No digital RTL is substituted for its electrical behavior.
