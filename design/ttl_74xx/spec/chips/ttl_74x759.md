# 74x759: quadruple non-inverting bus transceiver with open-collector outputs

**First manufacturer documentation:** December 1983 product preview; commercial introduction year is not established.
**Manufacturer source:** Texas Instruments, [1984 TTL Data Book Volume 3 supplement, SN54AS759/SN74AS758/SN74AS759 page](https://archive.org/details/bitsavers_tidataBookVol3_25840031/page/n527). Source pages are printed 2-495–2-497 (PDF page indices 527–529); the function table and positive-logic logic diagram are on printed page 2-495.
**Status:** implemented with an explicit state abstraction for the feedback-latch mode.

The TI table names the controls `GAB` with an overbar and `GBA` without an overbar. The interface uses `g_ab_n` for active-low GAB and `g_ba` for active-high GBA. The table is:

| `g_ab_n` | `g_ba` | Function |
|---:|---:|---|
| 0 | 0 | Transfer A to B; B receives A |
| 1 | 1 | Transfer B to A; A receives B |
| 1 | 0 | Isolation; neither bus is driven |
| 0 | 1 | Latch A and B with A = B |

Both ports are open-collector. RTL reports their logical output values and positive `*_drive` enables; while a driver is enabled, zero sinks and one releases to the pull-up. An inactive port has `*_drive=0`; its output value is normalized to zero and ignored.

## State abstraction and limits

The product-preview table names a feedback-latch mode and gives the relationship between its A and B values. The positive-logic diagram shows feedback paths, but the preview does not provide a separate latch timing/state-transition table. **ASSUMPTION:** in the digital model, the selected source bus is captured transparently while either transfer mode is selected; switching to latch mode holds the last transferred pair, with A = B. The RTL retains its last captured pair internally through isolation as a deterministic model choice, but the manufacturer preview does not define re-entry from an isolated or floating-bus condition. Conformance is claimed only when feedback mode follows an established directional transfer. It is unspecified until at least one such transfer occurs. During feedback, do not connect external drivers that contend with the part; the model ignores changes on its split `a_in`/`b_in` observations after entering feedback. This makes the feedback mode usable without adding a clock or reset that the part does not have, but the exact silicon capture/re-entry behavior has not been certified beyond the cited preview's table and diagram.

The model omits analog thresholds, open-collector current/voltage limits, delay, hazards and metastability. It does not resolve electrical contention; bus resolution is external.
