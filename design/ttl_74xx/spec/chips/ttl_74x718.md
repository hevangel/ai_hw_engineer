# 74x718: programmable binary down-counter

**First introduced:** Unknown; no confirmed first-shipment year found.
**Manufacturer references:** [Motorola 1983 Schottky TTL data book](https://bitsavers.trailing-edge.com/components/motorola/_dataBooks/1983_Motorola_Schottky_TTL_Data.pdf), PDF pages 399–405; [Motorola Phase-Locked Loop Systems Data Book (1973)](https://bitsavers.trailing-edge.com/components/motorola/_dataBooks/Motorola_Phase-Locked_Loop_Systems_Data_Book_2ed_Aug73.pdf), PDF pages 85–94 and 152.
**Status:** implementation-ready normalized digital model.

The Motorola numeric listing identifies the LS718 as a programmable binary counter equivalent to MC4018. The Motorola data book documents its equivalent modulo-N counter’s four positive-logic preset inputs, four outputs, positive-edge clock, active-low parallel enable, master reset, Gate, and Bus pins. The device counts down. The model omits propagation delay and the resistor/bias network on the Bus output.

## Logical function

| Condition | Action |
|---|---|
| `MR_n = 0` | Asynchronously clear `Q[3:0]` to zero. |
| `MR_n = 1`, `PE_n = 0` | Asynchronously load the preset value into `Q[3:0]`; the next positive clock edge begins counting down. |
| `MR_n = 1`, `PE_n = 1`, positive edge of `clock` | Decrement the 4-bit binary counter modulo 16. |
| `Q = 0`, `gate = 0`, Bus line high | Reload the preset value asynchronously. |
| `gate = 1` or Bus line low at `Q = 0` | Inhibit automatic preset; the counter continues through the binary sequence. |

The preset data is a 4-bit binary value from zero through fifteen. Taking `PE_n` low loads the data without waiting for a clock. Motorola calls PE an enable, describes a momentary low preload, and says the inputs are independent of the clock. For source-backed use, keep preset data stable for the full PE-low pulse; the source does not specify whether changes within the pulse pass through transparently, so this distinction is outside the model's conformance claim. At zero, `Bus` rises; with Gate low and the Bus line not forced low, this feedback reloads the preset. Holding Gate high or forcing the Bus line low inhibits reload and permits natural divide-by-sixteen counting.

`bus` is a normalized digital Bus level with a pull-up assumed: it is high at count zero unless `external_bus_low` represents another wired-AND participant pulling the shared line low. The physical pull-up/resistor pin and open-collector electrical behavior are outside the model. `external_bus_low` is an integration input representing the other participants on that line.

**Conformance limits:** For source-backed use, keep `preset` stable for the full `PE_n`-low pulse. The source does not state whether data changes during that pulse pass through transparently; RTL samples at the falling edge and that distinction is outside the claim. To enter documented zero, assert `MR_n` and `PE_n` low together. Manufacturer material gives no `MR`-alone priority table; RTL assumes asynchronous MR priority, which is not certified. The documented single-stage terminal sequence ties Gate to the clock: Bus rises at zero during the active clock phase, then preset reloads when the clock returns low. `gate` remains a separate port; tie it to `clock` for the documented single-stage divide phase. RTL normalizes feedback to asynchronous reload when `gate` is low and the wired Bus is high, so behavior for arbitrary independent Gate/clock waveforms and analog pulse width is not claimed. All controls are assumed to be settled to valid digital levels.

Source pages: Motorola 1983 PDF pages 399–400 identify LS718, give its modulo range/output sequence, the PE/reset description, and the pin/logic diagram; PDF pages 404–405 describe positive-edge countdown, asynchronous PE preload, Bus timing, and Gate connection. The 1973 book corroborates pin mapping and outputs on printed pages 78–81 (PDF pages 85–88), counting/preset behavior on printed pages 83–85 (PDF pages 90–92), and the MC4018 AN-541 preset sequence on printed page 145 (PDF page 152). Analog timing is excluded.
