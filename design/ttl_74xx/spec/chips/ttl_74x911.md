**Status:** implemented.

The MM74C911 holds four 8-bit digit registers (segment patterns a-g plus
decimal point, no decoding) written randomly by a CPU like a memory, and
multiplexes them onto one 8-segment driver set with four digit-strobe outputs
using its internal oscillator. The digit pins are bidirectional: a master
controller's strobes can drive cascaded slaves whose DIO input disables their
own scanner and turns the digit pins into inputs.

## Native digital contract

`d_in[7:0]` observes data inputs a,b,c,d,e,f,g,DP (pins 2-9, ascending bit
order). `k[1:0]` observes address inputs K1,K2 (pins 26,27; K1 in bit 0).
`ce_n` and `we_n` are the native active-low CE (pin 28) and WE (pin 1).
`soe_n` is Segment Output Enable (pin 16) and `dio_n` is Digit Input Output
(pin 10), both native active-low per the truth tables. `osc` replaces the
internal oscillator: each rising edge is one scan tick. `digit[3:0]` with
`digit_drive` are the digit pins D1-D4 (12-15) as outputs plus drive flag;
`digit_in[3:0]` observes the same pins for slave mode. `seg[7:0]` (a..g,DP in
ascending bit order) with `seg_drive` are the segment pins Sa-SDP
(17,18,19,20,21,23,24,25) as data plus drive flag.

Writing: with CE low and WE low, the register selected by K2,K1 (00=digit 1
.. 11=digit 4) transparently follows `d_in`; the value latches when either CE
or WE returns high (truth table rows "Write digit N" / "Latch digit N"). CE
high disables writing irrespective of WE. Address and data may change while
CE stays low; only the CE-low AND WE-low window writes.

Refreshing (DIO low): the scanner walks D1,D2,D3,D4 in ascending order,
`CYCLES_PER_DIGIT` ticks per digit, and inserts one blank tick (all digit
outputs low) between consecutive digits, mirroring the specified interdigit
blanking. During an active slot `digit` is one-hot, `digit_drive` is 1, and
`seg` presents the selected register when SOE is low. SOE high forces `seg`
to zero with `seg_drive` 0 while the digit scan continues ("Disable segment
outputs"). When DIO returns low the scanner resumes the phase it held.

Slave mode (DIO high): `digit_drive` is 0 and the scanner halts, preserving
its phase. The external one-hot pattern on `digit_in` selects which register
drives `seg` while SOE is low: 0001 shows digit 1 ... 1000 shows digit 4.
`digit_in` = 0000 selects nothing and `seg` releases (`seg_drive` 0; the
source's tD0 hold before Hi-Z is analog). DIO high with SOE high and no digit
selected is the source's power-saver quiescent state; all outputs are off.
Writes still work in slave mode; the register written is independent of the
register displayed.

ASSUMPTION: The internal RC oscillator is analog and outside the contract; the
model is externally clocked on `osc` (house 74x4060 precedent). The source
gives digit-on and interdigit-blank times but no digital ratio; the model uses
`CYCLES_PER_DIGIT` active ticks plus one blank tick. The scan starts at D1 and
ascends; the source shows sequential strobing but not the start phase.
Register contents and scanner phase power up unspecified; the model starts the
scanner at digit 1 slot phase 0. The master/slave register split is not
modeled; a write is visible to the scanner immediately. Digit-line inputs in
slave mode require the board to drive `digit_in`. tD1/tD0 skew and hold,
drive currents and analog thresholds are omitted.
