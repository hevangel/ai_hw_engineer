# 74x913: 6-digit BCD display controller and driver, no decimal point

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [National Semiconductor MM74C911/MM74C912/MM74C913
display controller advance-information datasheet, 1977 National CMOS
Databook](https://bitsavers.org/components/national/_dataBooks/1977_National_CMOS_Databook.pdf),
printed pages 1-122 to 1-124, PDF pages 137-139 (one-based). SHA-256:
`3e8c5ec749791505ac253578b0a12aeb0411f7f33272dfb8df35bd7f5e684227`. General
information and circuit description on PDF page 137; electrical
characteristics and write waveforms on PDF page 138; MM74C911 and
MM74C912/MM74C913 block diagrams on PDF page 139. This is the only
manufacturer document located for the MM74C913: it does not appear in the
1981 CMOS Databook, the 1984 CMOS Databook, or the 1984 Logic Databook
Volume 1 (all searched in full).
**Status:** implemented.

Per the 1977 source, "the MM74C913 will be identical to the MM74C912 except
that the decimal point input and output and the digit and segment tri-state
controls will be omitted." The model is therefore the 74x912 machine
(six 4-bit registers, CE/WE write protocol, self-scanned BCD-to-7-segment
ROM display) with the Dp path, the segment Output Enable, the digit
I/O control and the Oscillator Enable removed; the scanner runs whenever the
part is clocked, and the segment and digit outputs always drive.

## Native digital contract

`d[3:0]` observes data inputs a,b,c,d (block diagram input data buffers with
Dp omitted for the 913). `k[2:0]` observes address inputs K1,K2,K3. `ce_n`
and `we_n` are the native active-low chip-enable and write-enable per the
shared write description and waveforms: with CE low and WE low the addressed
register transparently follows `d`; the value latches when either returns
high. `osc` replaces the internal oscillator: each rising edge is one scan
tick. `digit[5:0]` is D1-D6 (least significant digit in bit 0), always
driven. `seg[6:0]` is Sa-Sg (a..g in ascending bit order), always driven;
there are no drive flags because the 913 has no tristated outputs.

The scan walks D1..D6 in ascending order, `CYCLES_PER_DIGIT` ticks per digit
with one blank tick between consecutive digits (the shared datasheet
specifies Digit On Time 400 us and Interdigit Blanking 50 us typical). During
an active slot `seg` presents the BCD decoding (font identical to the
MM74C912: 0-9 standard; 10=cdeg, 11=abfg, 12=a, 13=g, 14=d, 15=blank) of the
selected register's four data bits.

ASSUMPTION: The 1977 advance-information document prints no character font;
the table above is taken as identical to the shipping MM74C912 font (1984
National Logic Databook Volume 1, PDF page 1338) based on the source's
explicit statement that the 913 is identical to the 912 except for the
decimal point and the tristate controls. Addresses 110/111 are modeled as
null (no register written), matching the shipping MM74C912's "Null Digit"
rows; the 1977 document does not state their behavior. The RC oscillator is
analog and outside the contract; the model is externally clocked on `osc`
(house 74x4060 precedent). The blank tick is the normalized form of the
specified interdigit blanking. The scan starts at D1 and ascends; register
contents and scanner phase power up unspecified; the model starts the scanner
at digit 1 slot phase 0. Analog drive levels, thresholds and timings are
omitted.
