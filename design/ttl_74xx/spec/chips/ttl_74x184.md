## Functional baseline and interface notes

# ttl_74x184 — BCD to binary converter

Takes a 2-digit BCD value `{hi, lo}` packed into 8 bits and emits its
6-bit binary equivalent. Invalid BCD (digits ≥ 10) outputs 0.

Functionally equivalent to the lookup-table the original ROM-based 74184
implemented.


## Reviewed digital contract

This is a **normalized two-digit conversion interface**, not the original five-input ROM pinout or its complement outputs. `bin` is seven bits so all valid inputs 00–99 are represented without truncation. The original native converter bypasses the LSB and is cascaded for wider conversions; the normalized interface performs the complete digit conversion.
