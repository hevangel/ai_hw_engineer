# 74x3126: quad FET bus switch, output enable active high

First introduced: Unknown; the manufacturer publication date is not a confirmed
initial-shipment date. Primary source: [SN74CBT3126](https://www.ti.com/lit/ds/symlink/sn74cbt3126.pdf), table pages
1–2. SHA-256 `d5b05b648fe51612730fafa44da88d30620c7f97487b3c9de0224ef5c6bbbb30`.

FET bus switches provided low-delay board interconnects and memory-bus exchange
without directional logic buffers. This model retains their complete digital
topology and resolves both directions, including simultaneous connections.

## Control and port mapping

control[3:0] maps OE4..OE1, active 1; each controls 1 adjacent channels.
There are 2 ports, each 4 bits. Port index 0 is A (or A1 where noted).
`external_data[port*4+bit]` and `external_drive[port*4+bit]` describe **external
strong drivers only**. They must not be fed from a previous resolved bus value.
`resolved`, `valid`, `conflict`, and `weak_drive` use that same flattened ordering.

| Control | Connected port groups |
|---|---|
| 0 | channel 0 onward: all isolated |
| 1 | channel 0 onward: 0=1; channel 1 onward: all isolated |
| 2 | channel 0 onward: all isolated; channel 1 onward: 0=1; channel 2 onward: all isolated |
| 3 | channel 0 onward: 0=1; channel 2 onward: all isolated |
| 4 | channel 0 onward: all isolated; channel 2 onward: 0=1; channel 3 onward: all isolated |
| 5 | channel 0 onward: 0=1; channel 1 onward: all isolated; channel 2 onward: 0=1; channel 3 onward: all isolated |
| 6 | channel 0 onward: all isolated; channel 1 onward: 0=1; channel 3 onward: all isolated |
| 7 | channel 0 onward: 0=1; channel 3 onward: all isolated |
| 8 | channel 0 onward: all isolated; channel 3 onward: 0=1 |
| 9 | channel 0 onward: 0=1; channel 1 onward: all isolated; channel 3 onward: 0=1 |
| 10 | channel 0 onward: all isolated; channel 1 onward: 0=1; channel 2 onward: all isolated; channel 3 onward: 0=1 |
| 11 | channel 0 onward: 0=1; channel 2 onward: all isolated; channel 3 onward: 0=1 |
| 12 | channel 0 onward: all isolated; channel 2 onward: 0=1 |
| 13 | channel 0 onward: 0=1; channel 1 onward: all isolated; channel 2 onward: 0=1 |
| 14 | channel 0 onward: all isolated; channel 1 onward: 0=1 |
| 15 | channel 0 onward: 0=1 |


Connected components share their driven digital level. With conflicting strong
zero/one drivers, `conflict=1`, `valid=0` and `resolved=0` for every member of the
component. With no source, `valid=0`; floating data is masked zero. Equal multiple
drivers are valid. `weak=1` only when resolution uses a weak internal bias and
there is no strong driver.

ASSUMPTION: Ideal valid digital levels and settled controls; analog ON resistance,
threshold translation, delay and transient overlaps are excluded. Board networks
must combine all passive connections before resolving external drivers; cascading
already-resolved values as new drivers does not model a passive network correctly.
The topology is combinational and has no reset or invented clock.
