# 74x2003: 8-channel NMOS bidirectional level translator

**First introduced:** Unknown; the datasheet publication date is not verified as the first-shipment year.
**Manufacturer reference:** [SN74GTL2003 datasheet](https://www.ti.com/lit/gpn/sn74gtl2003), TI document SCDS305D (February 2011, revised September 2022). SHA-256: `d59069f5fece5173b1887c89a5159df2a5a749c49582066b656b742c1d68db5f`.

The SN74GTL2003 contains eight matched NMOS pass transistors, one per S/D channel pair, sharing the reference-controlled gate network. It has no per-channel direction or enable input: each channel supports bidirectional low-level transfer. TI describes the part as a GTL/GTL+ to LVTTL/TTL translator and gives an operating range of 0.95 V to 5 V in its feature summary. The reference transistor sets the low-side clamp level; it does not carry channel data.

## Digital interface and channel behavior

This model exposes two groups of eight digital ports. Flat vector index `channel` is `S(channel+1)` and index `8+channel` is the matching `D(channel+1)`, for channels 0–7. `external_data` and `external_drive` describe external Boolean sources only. They must not be fed from a prior `resolved` output. The `resolved`, `valid`, `conflict`, and `weak_drive` vectors use the same flat mapping.

With valid bias and Boolean levels, each S/D pair is one passive connected component:

| S-side external source | D-side external source | Result on both ports |
|---|---|---|
| Floating | Floating | `valid=0`, `resolved=0` |
| Driven 0/1 | Floating | Driven value, `valid=1` |
| Floating | Driven 0/1 | Driven value, `valid=1` |
| Same driven value | Same driven value | Driven value, `valid=1` |
| Opposite driven values | Opposite driven values | `conflict=1`, `valid=0`, `resolved=0` |

Channels resolve independently. This Boolean connectivity abstraction models the low-resistance ON path in both directions. It does not assert that an unpulled physical NMOS port reproduces a valid high voltage. External pull-ups and other board sources must be supplied through the external-driver interface when their logical effect is wanted. `weak_drive` is always zero because the IC has no internal channel pull-up or pull-down in the documented topology.

## Operating assumptions and limits

The TI pin table identifies S1–S8 as LVTTL/TTL source-side I/O and D1–D8 as GTL drain-side I/O; the reference pins are SREF, DREF, and GREF (datasheet p. 3). The functional overview says the transistor turns on when either side is low, allowing low-resistance bidirectional transfer; it describes the high level as set by SREF and external pull-ups (p. 8). Its functional-mode tables distinguish the reference-bias conditions under which the transistor is off, on, or nearly off (p. 9). This model omits analog reference pins and assumes a valid settled operating bias: GREF is tied to DREF and biased high, SREF is set to the intended low-side reference, and the operating conditions meet TI's recommendation that GREF be at least 1.5 V above SREF for best translator operation.

**ASSUMPTION:** The analog bias network is correctly configured and each external voltage has already been classified as a Boolean 0 or 1. The model abstracts enabled channel behavior as ideal, zero-delay connectivity. It omits voltage clamping, thresholds, analog pull-up strength, capacitance, propagation delay, transient overlap, hot-insertion behavior, and contention current. `external_drive=0` means no modeled external source; external resistor networks are not inferred. The model reports digital contention as `conflict` rather than modeling its analog electrical result.
