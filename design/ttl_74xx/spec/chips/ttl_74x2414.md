# 74x2414 memory decoder with supply monitor

First introduced: Unknown. The March 1989 document date does not establish shipment.
Manufacturer source: [SN74BCT2414](https://www.ti.com/lit/ds/symlink/sn74bct2414.pdf), printed pages 2-1 through 2-3.
SHA-256: `b2e5436ceee24dcd7c403d806b9674bdbd5267dde6ed46ed29890cbfe9606509`.

This battery-backed memory decoder isolates memory selections on supply failure.
Its two 2-to-4 decoders can form a 3-to-8 decoder with complementary bank enables.

## Digital contract

`address_1[1:0]={1B,1A}`, `address_2[1:0]={2B,2A}`.
Y bit indices map Y0..Y3 and each enabled decoder asserts exactly one low output.
`sd_n=0` shuts down both decoders; `g_n=1` disables both. The first bank's
`g1_n` is active low, while the second bank's `g2` is active high. Native controls
are asynchronous combinational inputs. All Y outputs are high when disabled.

ASSUMPTION: `supply_good` is the already-classified output of the native VCC
voltage monitor (nominal threshold 3.65 V). Vbat powers valid digital logic.
Analog threshold, hysteresis, voltage ramps and switching delays are omitted.
`supply_good=0` immediately forces all Y high and releases the open-collector VS
output. `vs_drive_low=supply_good`; `vs` observes the externally pulled-up level.
This monitor is independent of the decoder's SD/G and per-bank enables.
