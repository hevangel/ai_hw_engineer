# 74x4059: programmable divide-by-N counter

**First introduced:** Exact first-introduced year not established.
**Manufacturer reference:** [TI CD74HC4059 datasheet](https://www.ti.com/lit/gpn/cd74hc4059).
**Digital model:** Rising-edge programmable divider with jam-programmed first,
intermediate, and final counting sections. Package timing and electrical
characteristics are outside this logical model.

The 4059 divides an input clock by a programmed value. Three mode inputs select
the modulus of the first counting section. Sixteen jam inputs preset that
section, three intermediate decimal-weighted stages, and (in four modes) a
final counting section. The output is one clock wide by default. The master
preset mode loads the jammed state and holds it until a divide mode is selected.

## Mode select table

`K[2:0]` is ordered `{Ka, Kb, Kc}`.

| Ka | Kb | Kc | Mode | First section | First jam bits | Final section | Final jam bits | Nominal max N | Extended max N |
| --- | --- | --- | --- | ---: | --- | ---: | --- | ---: | ---: |
| 1 | 1 | 1 | ÷2 | 2 | J1 | ÷8 | J2–J4 | 15,999 | 17,331 |
| 0 | 1 | 1 | ÷4 | 4 | J1–J2 | ÷4 | J3–J4 | 15,999 | 18,663 |
| 1 | 0 | 1 | ÷5 | 5 | J1–J3 | ÷2 | J4 | 9,999 | 13,329 |
| 0 | 0 | 1 | ÷8 | 8 | J1–J3 | ÷2 | J4 | 15,999 | 21,327 |
| 1 | 1 | 0 | ÷10 | 10 | J1–J4 | ÷1 (none) | — | 9,999 | 16,659 |
| X | 0 | 0 | Master preset | Loads jam inputs and holds | | | | | |

`X` means Ka is a don't-care in master preset mode. `K=010` is not assigned a
mode in the manufacturer truth table; the RTL holds its counter state and
generates no new output pulse for this unsupported selection.

The nominal range uses values 0–9 for each intermediate stage. The datasheet
also permits 10–15 in each 4-bit stage, extending the range without changing
the stage weights. Values 10–15 are therefore meaningful presets, not invalid
BCD states.

## Jam input encoding

The jam port is represented as `j[15:0]`, with `j[0]` corresponding to J1 and
`j[15]` to J16. Within a group, the lowest-numbered J input is the least
significant bit. The groups encode:

- J1–J4: first-section preset in the low bits selected by the mode, with any
  remaining high bits encoding the final-section preset. For example, in ÷5,
  J1–J3 encode the first value and J4 encodes the final value.
- J5–J8: `D1`, the units-weighted intermediate preset.
- J9–J12: `D10`, the tens-weighted intermediate preset.
- J13–J16: `D100`, the hundreds-weighted intermediate preset.

Let `M` be the first-section modulus, `R` its preset, `L` the final-section
preset (zero in ÷10 mode), and `D1`, `D10`, and `D100` the intermediate
presets. The programmed divide value is:

```text
N = M × (1000 × L + 100 × D100 + 10 × D10 + D1) + R
```

This matches the TI example for N=8479 in ÷5 mode: `L=1`, `D100=6`,
`D10=9`, `D1=5`, and `R=4`, giving `5 × (1000 + 600 + 90 + 5) + 4`.
The extended ÷8 example uses `L=1`, all three intermediate presets at 15, and
`R=7`, giving N=21,327.

## Clocking and output behavior

- CP is sampled on its rising edge.
- The first section consumes a nonzero remainder `R` first, without changing
  the quotient fields; it then counts the quotient's full M-clock intervals.
  If R is zero, the first interval is a full M clocks. Thus the quotient fields
  decrement once per full interval, matching `N = M × quotient + R`.
- On terminal count, Q asserts for one clock period when LE is low, and the
  programmed jam count is reloaded for the next period.
- A high LE latches an active Q pulse high. While LE remains high, Q stays
  high after the registered pulse ends. Returning LE low asynchronously clears
  the held extension without waiting for another CP edge. If LE remains low,
  Q is the normal one-CP-cycle pulse. This models the LE-to-Q behavior shown in
  the datasheet; physical propagation delay is not simulated.
- Master preset is selected when Kb=0 and Kc=0. The datasheet requires at
  least three full CP pulses in this mode and specifically requires it before
  selecting ÷5. On leaving master preset, the first positive CP edge performs
  internal setup and counting begins at the second edge, adding one startup
  clock to the first output after the mode change.
- This device has no reset pin. Counter state is unspecified at power-up; use
  master preset before relying on the divide sequence.

## Scope and assumptions

The RTL models the documented synchronous divider, jam decoding, preset hold,
registered output pulse, and level-sensitive LE hold with asynchronous digital
release. It omits propagation delay (including the datasheet's LE-to-Q delay),
setup/hold timing, and electrical limits. For the unsupported `K=010` code, hold-state
behavior is a deterministic simulation assumption because the TI mode table
does not specify that combination. The model requires master preset to
initialize simulation state, consistent with the datasheet's prescribed
initialization procedure.
