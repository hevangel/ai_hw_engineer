The source supplies the control table, native package pinout, output type and

board-bus direction control with local data retention using dual feedback paths.

## Native routing and qualified storage

`a_in/a_out[7:0]` maps A1..A8; B vectors map B1..B8. `g_ba_n` is native
active-low GBA, `g_ab` native active-high GAB. Routed data is
inverted. The full control table is:

| GBA | GAB | Operation |
|---|---|---|
| 0 | 0 | B to A |
| 1 | 1 | A to B |
| 1 | 0 | Both isolated |
| 0 | 1 | Both directions enabled, retaining complementary A/B values |

Both buses use three-state outputs. A positive drive flag enables the complete byte; otherwise the port is released.
All disabled output data is masked to zero. There is no clock or reset.

The source explicitly describes latch retention when both paths are enabled and
**all other data sources are high impedance**. ASSUMPTION: Capture the source
transparently during a directional transfer and hold the resulting pair in
feedback mode. Feedback mode is qualified only after an established directional transfer, with all external data sources released. Re-entry from isolation and overwriting driven feedback buses are uncertified; retained state through isolation is a deterministic model choice. Storage is unspecified until a directional transfer.
Board inputs are externally resolved observations; input changes during the
qualified feedback hold do not overwrite storage. No claim is made for electrical
contention or floating initial buses. This is the same explicit abstraction used
for the related 758/759 feedback transceivers.

Analog voltage/current, propagation delay, hazards, and series output resistors and electrical resolution
are omitted. Use valid powered logic and settled controls.
