## Functional baseline and interface notes

# ttl_74x62 — 3-3-2-2 AND-OR expander

A 3-3-2-2 AND-OR network used as an external expander for the 74x50/53/55
AOI gates. Digital-only approximation; the expander's internal-node
interface cannot be modeled in RTL.
