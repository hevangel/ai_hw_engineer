# 74x912: 6-digit BCD display controller and driver

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [National Semiconductor MM74C912 6-Digit BCD Display
Controller/Driver, 1984 National Logic Databook Volume 1](https://bitsavers.org/components/national/_dataBooks/1984_National_Logic_Databook_Volume_1.pdf),
printed pages 6-180 to 6-185, PDF pages 1335-1340 (one-based). SHA-256:
`9d487da7c77326e8e6578fb8c7680643e400044f05d8a74ec152a56c8e3af252`.
Connection diagram and input/output control truth tables on PDF page 1335;
character font table, segment identification and block diagram on PDF page
1338; write/multiplexing waveforms and AC parameters on PDF pages 1336-1337;
typical application on PDF page 1340. The earlier combined advance-information
datasheet in the [1977 National CMOS Databook](https://bitsavers.org/components/national/_dataBooks/1977_National_CMOS_Databook.pdf)
(SHA-256 `3e8c5ec749791505ac253578b0a12aeb0411f7f33272dfb8df35bd7f5e684227`,
PDF pages 137-139) was visually reviewed; the shipping 1984 document is used
as the controlling source.
**Status:** implemented.

The MM74C912 holds six 5-bit registers (four BCD data bits plus decimal
point) written randomly like a memory, and self-scans them through an
internal BCD-to-7-segment ROM onto one segment output set with six
digit-strobe outputs. OSE stops the automatic refresh; SOE tristates the
segment drivers.

## Native digital contract

`d[3:0]` observes data inputs A,B,C,D (pins 3-6, A=2^0 in bit 0). `dp` is the
decimal-point input (pin 7); it does not address the ROM and goes directly to
the Sdp output. `k[2:0]` observes address inputs K1,K2,K3 (pins 26,27,28; K1
in bit 0). `ce_n`, `we_n` are the native active-low CE (pin 1) and WE (pin 2).
`ose_n` is Oscillator Enable (pin 8, active low: high stops the scan) and
`soe_n` is Segment Output Enable (pin 16, active low), both per the truth
tables. `osc` replaces the internal oscillator: each rising edge is one scan
tick. `digit[5:0]` is D1-D6 (pins 14,13,12,11,10,9; D1 least significant
digit in bit 0); the digit outputs have no tristate control and always drive.
`seg[6:0]` (a..g in ascending bit order, pins 17,18,19,21,22,23,24) with
`seg_drive` and `seg_dp` (pin 25) with the same flag are the segment outputs
as data plus drive flag.

Writing: with CE low and WE low, the register selected by K3,K2,K1
(000=digit 1 ... 101=digit 6, per the input-control truth table)
transparently follows {dp,d}; the value latches when either CE or WE returns
high. Addresses 110 and 111 are "Write/Latch Null Digit": no register is
affected. CE high disables writing irrespective of WE.

Refreshing (OSE low): the scanner walks D1..D6 in ascending order,
`CYCLES_PER_DIGIT` ticks per digit, and inserts one blank tick (all digit
outputs low) between consecutive digits, mirroring the specified interdigit
blanking. During an active slot `digit` is one-hot and `seg`/`seg_dp` present
the ROM decoding of the selected register when SOE is low. SOE high forces
the segment outputs to zero with `seg_drive` 0 ("Disable Segment Outputs")
while the scan continues. OSE high freezes the scanner on the current digit
slot (no blanking is inserted while frozen): the displayed digit stays
statically driven, matching the source note that segment drive may then
exceed maximum display dissipation.

Character font (PDF page 1338, segments a,b,c,d,e,f,g in `seg` bits 0..6),
identical for data 0-9 in both devices: 0=abcdef, 1=bc, 2=abdeg, 3=abcdg,
4=bcfg, 5=acdfg, 6=acdefg, 7=abc, 8=all, 9=abcdfg. MM74C912 codes 10-15:
10=cdeg (lower o), 11=abfg (raised o), 12=a, 13=g, 14=d, 15=blank. SOE high
shows Hi-Z (the table's first column), modeled by `seg_drive` 0.

ASSUMPTION: The internal RC oscillator is analog and outside the contract;
the model is externally clocked on `osc` (house 74x4060 precedent). The blank
tick per digit boundary is the normalized form of the specified interdigit
blanking time (tIB). The scan starts at D1 and ascends; the source shows
sequential strobing (digit N then digit N+1) but not the start phase.
Register contents and scanner phase power up unspecified; the model starts
the scanner at digit 1 slot phase 0. "Null Digit" is modeled as a no-op
write; the truth table names the operation but does not elaborate. When OSE
freezes the scanner, which digit is frozen depends on the stop instant; the
model holds the active slot including its remaining ticks. Analog drive
levels, thresholds and timings are omitted.
