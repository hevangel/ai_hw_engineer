## Functional baseline and interface notes

# ttl_74x224 — FIFO

16-word x 4-bit synchronous FIFO. Posedge-clocked write
(`we`) and read (`re`). Async active-low clear. `full` and `empty`
flags.

Writes when full and reads when empty are ignored. This is an FPGA-
synthesis-friendly behavioral model — the original chip's async write/
read timing details are not preserved.


## Integration assumptions

ASSUMPTION: This FIFO uses normalized synchronous `we`/`re` transactions on `clk`. The original asynchronous request/ready handshake and its propagation timing are not native pins here.
