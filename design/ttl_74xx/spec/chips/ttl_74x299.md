## Functional baseline and interface notes

# ttl_74x299 — 8-bit bidirectional universal shift register with 3-state outputs

Like `ttl_74x198` with an OE_n output gating.


## Reviewed digital contract

`drive_en` is the per-bit output-drive mask: 1 drives, 0 releases. The data output keeps its deterministic masked-zero value while disabled. For a resolved external bus use `drive_en[i] ? data[i] : 1'bz`. This avoids confusing a disabled output with a driven zero.

## Serial and parallel output behavior

`q0` and `q7` always expose the stored serial endpoints, even while the parallel bus is disabled. The parallel `drive_en` mask is zero in parallel load mode (`s1=s0=1`) to permit the external source to drive the shared pins. `p` and `q` are split data input/output buses.
