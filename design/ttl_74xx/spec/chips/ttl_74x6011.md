# 74x6011: LSTTL-to-CMOS inverting open-collector optocoupler

**First introduced:** Unknown; the manufacturer datasheet date does not establish the first-shipment year.
**Manufacturer source:** [Fairchild 74OL6000/6001/6010/6011 datasheet](https://datasheet.datasheetarchive.com/originals/distributors/Datasheets-12/DSA-229129.pdf), copyright 2002, dated June 10, 2002.

The Fairchild device-configuration table identifies 74OL6011 as an LSTTL-input, CMOS-output inverter with an open-collector output (datasheet p. 2). It maps pin 2 `VIN` as data input and pin 5 `VO` as data output. Its internal logical output is `~VIN`; the external output transistor sinks low when that logical output is 0 and releases when it is 1. The digital interface reports this as `vo_drive_low = VIN`.

| VIN | Logical output | `vo_drive_low` |
|---:|---:|---:|
| 0 | 1 | 0 (released) |
| 1 | 0 | 1 (sink) |

An external pull-up is required to obtain a high voltage while the open collector is released; this model reports the sink control and does not model an external pull-up. The package exposes a logic input, not a separate LED or enable pin. Fairchild describes the internal input amplifier and LED drive in the device description (p. 1).

**ASSUMPTION:** The optocoupler is powered within its recommended ranges and VIN is a valid LSTTL logic level; the model is a two-state Boolean function. `vo_drive_low` is an active-high digital sink-enable flag. External pull-up voltage/strength, output current, isolation, LED current, optical transfer, and propagation delay are omitted.
