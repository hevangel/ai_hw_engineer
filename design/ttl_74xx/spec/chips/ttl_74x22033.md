# 74x22033: 8-bit LVTTL-to-GTLP adjustable-edge-rate registered transceiver with split LVTTL port and feedback path

**Manufacturer source:** Texas Instruments SN74GTLP22033, SCES354C (June 2001, revised September 2001), [official TI datasheet](https://www.ti.com/lit/ds/symlink/sn74gtlp22033.pdf); the package pinout is on PDF page 1 and the complete function tables on PDF pages 4-5 of the cached manufacturer PDF, SHA-256 `5ae9deee9c4f622aca8e3207c2dbe6ff8919ee36c02d6736f9ea865f95e50602` (function tables visually verified against rendered page images).

An 8-bit registered transceiver between an LVTTL side (split into separate AI
inputs and AO outputs, giving a feedback path for control and diagnostics) and
a GTLP backplane B port. Each transfer path independently selects a buffer,
flip-flop, or latch logic element, and every path inverts: the B bus and AO
outputs carry the inverted selected-element output.

## Logical contract

`ai[7:0]` observes package AI1..AI8, `bi[7:0]` observes the resolved B1..B8
bus, and `ao[7:0]` drives AO1..AO8. The B port is open-drain GTLP (100 mA
low-state drive, no high-state drive), so `b_drive` is the low-only sink mask
for the inverted path output; the B high level comes from board termination.

Output enables follow the source enable/disable table exactly:
`b_enable = oeab && !oeab_n` (both native pins 44 and 41 must be asserted),
and AO drives while `oeba` is high. The two enables are independent.

Mode selects per the SELECT table (applied to the B path via `omode` and to the
AO path via `imode`): `00` = buffer, `01` = flip-flop, `1X` = latch. The B-path
element processes `ai` and clocks/latches on `clkab_leab`; the AO-path element
processes Q and clocks/latches on `clkba_leba`. Flip-flop paths capture on
rising edges; the latch is transparent while its CLK/LE pin is high and holds
otherwise.

| Path | Input | Element | Native output |
|---|---|---|---|
| A-to-B | AI | buffer / FF / latch per OMODE | B bus sinks the inverted element output while enabled |
| B-to-AO | Q | buffer / FF / latch per IMODE | `ao = !element output` while enabled |

The LOOPBACK table defines Q: `loopback` low selects the B port observation,
`loopback` high selects P, the output of the A-to-B logic element, creating the
source's transparent-with-feedback diagnostics configuration where the B-path
element result is routed straight into the B-to-AO path.

ASSUMPTION: Native setup/hold windows are not modeled; storage powers up
unspecified. `b_drive` is an explicit low-only sink indication; board models
must supply termination pullups, resolve the bus, and only then feed `bi`.
Masked outputs are zero and ignored by board adapters. The ERC edge-rate input
and the VREF/BIAS VCC references are analog and omitted.
