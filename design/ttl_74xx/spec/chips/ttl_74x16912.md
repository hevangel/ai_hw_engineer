# 74x16912: 18-bit LVTTL-to-GTLP universal bus transceiver

**Manufacturer source:** Texas Instruments SN74GTLPH16912, SCES288C (October 1999, revised July 2001), in the official [TI GTLP design guide SCED004A](https://www.ti.com/lit/ug/sced004a/sced004a.pdf), printed pages 3-221 to 3-232; the package pinout is on book PDF page 278, the description on PDF page 279, and the function table on PDF page 280. Book PDF SHA-256: `414fb09c44deff6897c9fdf90ea9b59f9f592e5f78067cb4d65d80018799a995`.

A 50 mA high-drive 18-bit universal bus transceiver (UBT) combining D-type
latches and D-type flip-flops for transparent, latched, clocked, or
clock-enabled operation between LVTTL and GTLP backplanes. Data polarity is
noninverting. Except for the 18-bit width and the absence of the ERC edge-rate
pin this is the same UBT contract as the SN74GTLPH1612.

## Logical contract

The A port is LVTTL (push-pull); the B port is GTLP and sinks only — the source
lists low-state B-port output current and no B-port high-state drive, so the B
high level comes from board termination. `a_in[17:0]`/`b_in[17:0]` observe
package A1..A18/B1..B18. `a_out`/`a_drive` carry the B-to-A push-pull output
state; `b_drive` is the A-to-B low-only sink mask for the open-drain B port.

Each direction is controlled independently. For A-to-B: `oeab_n` (active low)
enables B outputs, `ceab` (active high) inhibits the clock when high, `leab`
follows A transparently while high and captures on its falling edge, and `clkab`
captures A on rising edges. B-to-A is identical with `oeba_n`, `ceba`, `leba`,
`clkba` and B-port data. Per the function table (A-to-B shown; B-to-A similar):

| CEAB | OEAB_n | LEAB | CLKAB | B output | Mode |
|---|---|---|---|---|---|
| X | 1 | X | X | released | Isolation |
| 0 | 0 | 0 | 1 | B0 | Latched storage of A data |
| 0 | 0 | 0 | 0 | B0 | Latched storage of A data |
| X | 0 | 1 | X | A live | True transparent |
| 0 | 0 | 0 | rising | A captured | Clocked storage of A data |
| 1 | 0 | 0 | X | B0 | Clock inhibit |

B0 is the output value held from before the input conditions were established.
The source does not recommend OEAB and OEBA low simultaneously; this model lets
both banks drive and the board model resolves the resulting contention.

VREF and BIAS VCC are analog references and are omitted from this
pure-digital contract; this device has no ERC edge-rate pin.

ASSUMPTION: This model uses the shared library UBT abstraction: the transparent
and stored output paths collapse into one state element per direction that
tracks its input while LE is high and holds the last transparent value after LE
falls. Native qualified LE transitions are therefore not separately observable,
and native setup/hold windows are not modeled. Register contents power up
unspecified. `b_drive` is an explicit low-only sink indication; board models
must supply termination pullups, resolve the bus, and only then feed `b_in`.
Masked outputs are zero and ignored by board adapters.
