## Local collector contract

`q` uses logical pull-up levels: disabled parallel outputs return all ones (release).
The two register stages retain state while output enable is inactive. The local
test checks every byte, independent clocks, shift clear preserving storage and
simultaneous clocks. Board-level OC resolution must use wired AND.
