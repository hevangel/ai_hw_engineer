# 74x793: 8-bit latch, readback

First introduced: Unknown; the source book establishes documented availability,
not a confirmed first-shipment date. [Manufacturer artifact](https://archive.org/download/MonolithicMemories-MMI-BipolarLSI1984DatabookOCR/MonolithicMemories-MMI-BipolarLSI1984DatabookOCR.pdf), PDF page 451, printed 13-60 (tables and logic symbols).
SHA-256: `30c71abee89bf5d401bbf044e1d8b9483da4cb7351ef6013dff4911921ca21b2`.

These parts made board-level bus readback, diagnostic scan and buffered data
movement available without a processor or a custom logic array.

## Native digital contract

`d_in[7:0]` observes the package D0..D7 bus; `q[7:0]` is the
always-driven dedicated Q0..Q7 output. `oe_n=0` enables readback onto D through
`d_out` and `d_drive`. It does not disable Q. While reading back, native output
feedback preserves storage, including clock edges on the 794. `d_in` represents
external input only in input mode (`oe_n=1`).

The 793 is transparent while `g=1` and `oe_n=1`; lowering G holds the last data.
ASSUMPTION: G is low during readback. The manufacturer marks G high with readback
enabled as a race/hazard condition, not normal operation. The Boolean model holds
the last value in that self-feedback condition; it does not characterize the hazard.


ASSUMPTION: Valid powered logic levels, setup/hold and noncontentious board buses.
Storage starts unspecified; initialize through native controls. Analog propagation,
voltage thresholds, drive strength and hazards are omitted. Split output data is
zero while its positive drive flag is low; consumers must resolve the actual bus.
