# SN74GTL2007: 12-bit GTL/GTL+ to LVTTL translator with enables

**Historical date:** TI datasheet SCLS609 is dated March 2005; the product's exact first-introduction date is not established here.
**Manufacturer source:** [TI SN74GTL2007 datasheet](https://www.ti.com/lit/gpn/sn74gtl2007), function tables p. 2 and logic symbol p. 3.
**Status:** implemented as a digital logic model.

## Function

Vector bit 0 is channel suffix 1 and bit 1 is suffix 2. An `_drive_low` output is an open-drain sink flag. LVTTL OD pads resolve as `drive_low ? 0 : external_drive ? external_data : 1`; GTL input levels are preclassified against VREF. An external high against an internal sink resolves low in this ideal wired-AND model; analog contention is excluded.

- `EN1=1` makes `AO1/AO2=BI1/BI2`; `EN1=0` forces both push-pull LVTTL outputs high. `EN2` does the same for `BI3/BI4` to `AO3/AO4`.
- `AO9=BI9` (push-pull LVTTL output).
- For channels 5 and 6, `a_5_6_drive_low[i] = en2 & !bi_5_6[i]`. With the resolved 5A/6A levels, `bo_7_drive_low[i] = bi_5_6[i] & !a_5_6_bus[i]`. EN2 controls the LVTTL OD drive; the GTL return path still observes the actual external bus when EN2 is low.
- `bo_8_drive_low = !ai_8`.
- `bo_10_drive_low[i] = !(ai_10[i] & bi_9)` for separate AI1/AI2 channels.
- `a_11_drive_low = bi_11`; `bo_11_drive_low = a_11_bus`.

The 7BO output-enable path has an analog glitch-suppression delay in the datasheet. Only the stable-state table is modeled.

## Scope assumptions

VCC is valid, VREF classification is already applied, and bus pull-ups are represented by a high value when no device drives. Thresholds, power-up isolation, timing, drive strength, termination, and analog contention are excluded. Package supply pins are not module ports.
