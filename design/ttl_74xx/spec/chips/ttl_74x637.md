# 74x637: normalized 8-bit SECDED function

First introduced: Unknown. The manufacturer source remains linked in the
[manifest](../../manifest.json). This function demonstrates board-level
single-error correction and double-error detection; it is useful for memory buses.

## Explicit normalized code contract

**ASSUMPTION:** This is an extended Hamming code with positive parity. Data bit
positions are `[3, 5, 6, 7, 9, 10, 11, 12]`; powers of two are check positions, and the highest
check bit is overall even parity. **This matrix is not asserted to be the native
manufacturer's matrix or package-pin interface.** It is not a drop-in chip model
for existing check-bit wiring. The imported implementation was also normalized,
and incorrectly overlapped check/data syndrome columns; this replaces it.

`mode_n=0` generates checks; `mode_n=1` checks/corrects the input word using
`check_in`. Any one data or check bit is correctable; any two encoded-word bits
are detected. More than two errors have no classification guarantee. `check_out`
always encodes the presented data, while `data_out` is corrected in check mode.
For byte-write variants a high byte_we bit preserves the corresponding orig_data
byte only when generating checks; check mode uses data_in unchanged.

Tests use precomputed parity literals, all one-bit faults in the entire codeword,
all double faults for a representative codeword, and byte merge cases.
