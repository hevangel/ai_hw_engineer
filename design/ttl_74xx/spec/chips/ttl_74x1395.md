# SN74GTLP1395: dual 1-bit GTLP/LVTTL transceiver with independent controls

**Historical date:** TI datasheet SCES349C is dated June 2001, revised January 2006; the exact product introduction date is not established here.
**Manufacturer source:** [TI SN74GTLP1395 datasheet](https://www.ti.com/lit/gpn/sn74gtlp1395), functional description and tables p. 3; package pin configuration p. 1.
**Status:** implemented as a digital logic model.

## Function

Two lanes use bit 0 for channel 1 and bit 1 for channel 2. Each lane has independent `tc`, active-low `oeab_n`, and active-low `oeby_n`. `tc=1` selects true transfer; `tc=0` complements in both directions. For each lane, `b_output_data = tc ? a_in : ~a_in` with B enabled when `oeab_n=0`; `y_output_data = tc ? b_bus_in : ~b_bus_in` with Y enabled when `oeby_n=0`. The separate B bus input represents the externally resolved GTLP level used for feedback. Disabled outputs are high impedance and their data values are ignored. This preserves independent A→B and B→Y control and simultaneous feedback operation.

The datasheet specifies `ERC=1` as slow and `ERC=0` as fast for this part; RTL reports this mode as `b_edge_fast = !erc`. ERC changes analog edge rate only.

## Scope assumptions

Valid VCC/VREF/BIAS supplies and logic-level inputs are assumed. GTLP electrical levels, threshold conversion, analog edge rate, delays, output drive strength, power-up 3-state behavior, and live insertion are excluded. Supply and ground terminals are omitted from the functional model.
