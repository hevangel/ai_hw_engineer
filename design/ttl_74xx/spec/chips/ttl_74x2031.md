## Native digital contract

`a_in[8:0]` observes TTL A-port pins A1..A9 in bits 0..8; `b_in[8:0]` observes
resolved BTL B-port pins B1..B9 in bits 0..8 (1 = line released by every
driver, 0 = line asserted low by at least one driver). `oea` is the active-high
A-port output enable. `oeb` (active high) and `oeb_n` (active low) jointly
enable the B port: B drives only while `oeb=1` and `oeb_n=0`. This reproduces
every row of the transceiver function table: `oeb=0` or `oeb_n=1` turns the B
port off, `oea=0` isolates the A port, and with `oea=1, oeb=1, oeb_n=0` both
directions transfer simultaneously. `lca`, `lcb`, `sel1`, `sel0` are the
storage controls. `a_out[8:0]` is the three-state A-port data with scalar
bank-enable flag `a_drive` (the A port is one bank gated only by OEA).
`b_drive[8:0]` carries per-pin open-collector sink flags following the 16246
precedent: flag 1 means the pin actively sinks its line low, flag 0 means the
pin is released; `b_out[8:0]` is always zero and board adapters ignore it.

Data is inverted between the ports, per the description: the B port receives
"A-bar data" (an A pin high sinks the corresponding B pin) and the A port emits
"B-bar data" (real-time `a_out = ~b_in`). SEL1/SEL0 choose the storage element
exactly as in the SELECT FUNCTION TABLE:

| sel1 | sel0 | MUX A→B   | MUX B→A   |
|------|------|-----------|-----------|
| 0    | 0    | latch     | latch     |
| 0    | 1    | thru      | thru      |
| 1    | 0    | flip-flop | flip-flop |
| 1    | 1    | flip-flop | latch     |

Per the STORAGE MODE TABLE, each `l*` control acts as latch enable when its
direction selects the latch and as a positive-edge clock when it selects the
flip-flop: `lca=0` makes the A→B latch transparent, `lca=1` holds it; a rising
edge of `lca` captures the A→B flip-flop. `lcb` controls the B→A elements the
same way. The A→B elements store unmodified A data; the B→A elements store
`~b_in` (TTL-domain data), so stored outputs emerge with the same inter-port
inversion as real-time transfers. Thru mode bypasses storage combinationally.

ASSUMPTION: Both storage elements of a direction stay live regardless of the
SEL mux position (the diagram feeds A1 to both the latch and the flip-flop);
SEL only selects which element drives the output.

ASSUMPTION: Latch and flip-flop power-up contents are unspecified; they must be
loaded through their transparent/clock paths before their outputs are relied
on. Valid setup/hold around `lca`/`lcb` edges are required, as on the native
part.

ASSUMPTION: Externally resolved powered logic. The IEEE 1149.1 pins allocated
on the package are no-connects in this product-preview version (TMS and TCK
not connected, TDI shorted to TDO) and are omitted. BIAS Vcc, BG Vcc, BG GND,
the B-port bias network, the 2 ns minimum edge rate, sink current, Vcc < 2.5 V
power-off isolation, thresholds and timing are analog/electrical behavior and
are omitted. The block-diagram page contains preview-quality pin-number typos
(for example A1 shown as RC pin 20 instead of 50); the pinout page and the
function tables are treated as authoritative.
