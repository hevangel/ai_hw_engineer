# 74x6000: LSTTL-to-TTL non-inverting optocoupler

**First introduced:** Unknown; the manufacturer datasheet date does not establish the first-shipment year.
**Manufacturer source:** [Fairchild 74OL6000/6001/6010/6011 datasheet](https://datasheet.datasheetarchive.com/originals/distributors/Datasheets-12/DSA-229129.pdf), copyright 2002, dated June 10, 2002.

The Fairchild device-configuration table identifies 74OL6000 as an LSTTL-input, TTL-output buffer with a totem-pole output (datasheet p. 2). It maps pin 2 `VIN` as data input and pin 5 `VO` as data output. The digital function is `VO = VIN`.

| VIN | VO |
|---:|---:|
| 0 | 0 |
| 1 | 1 |

The input pin is the logic data input to the integrated input amplifier. Fairchild says that amplifier controls the internal LED current source (p. 1), but the package has no separate enable, LED-drive, or LED pins. Therefore the model preserves the published VIN-to-VO logic function and does not invent a separately observable optical-drive signal.

**ASSUMPTION:** The optocoupler is powered within its recommended ranges and VIN is a valid LSTTL logic level; the model is a two-state Boolean function. Output drive strength and voltage, isolation, LED current, optical transfer, and propagation delay are omitted. The totem-pole output is represented as a push-pull Boolean `vo`.
