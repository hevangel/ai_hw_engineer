# 74x818: 8-bit diagnostic register

First introduced: Unknown; the source book establishes documented availability,
not a confirmed first-shipment date. [Manufacturer artifact](https://archive.org/download/bitsavers_fairchilddldFACTLogicDataBook_27153725/1987_Fairchild_FACT_Logic_Data_Book.pdf), PDF pages 413–415 / printed 5-346–5-348.
SHA-256: `e8054594a38e14a45fdc86d2708a143e7fa2f086e989cce166cdb62b5e48e49d`.

These parts made board-level bus readback, diagnostic scan and buffered data
movement available without a processor or a custom logic array.

## Native digital contract

The diagnostic (S) and
pipeline (P) registers have independent rising-edge clocks `dclk` and `pclk`.
`d_bus_in` and `y_bus_in` are resolved samples of the physical D0..D7 and Y0..Y7
pins; bit index 0 maps pin suffix 0. `oe_y_n=0` enables Y from P.

On DCLK with `mode=0`, S shifts toward bit 7 and SDI enters bit 0. With `mode=1`
and `sdi=0`, S captures **the Y bus observation**, including an external value
when Y is disabled. With `mode=1,sdi=1`, S holds. The D-port drive enable is a
separate flip-flop capturing `mode && sdi` on DCLK (source block diagram); it
remains unchanged between DCLK edges. Enabled D outputs contain S.

On PCLK, `mode=0` captures D and `mode=1` captures S. Simultaneous clocks use
pre-edge values: they may swap the two register contents when Y drives P.
`sdo` is combinational S7 in mode 0 and SDI in mode 1, including while clocks stop.
There is no reset. The board must resolve driven D/Y outputs back to the input
observations; this model does not invent a feedback value for a disabled pin.

ASSUMPTION: Valid powered logic levels, setup/hold and noncontentious board buses.
Storage starts unspecified; initialize through native controls. Analog propagation,
voltage thresholds, drive strength and hazards are omitted. Split output data is
zero while its positive drive flag is low; consumers must resolve the actual bus.
