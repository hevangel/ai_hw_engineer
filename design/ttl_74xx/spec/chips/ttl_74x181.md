# 74181 family entry point

First introduced: **1970**; exact month disputed. See the sourced
[historical overview](../../README_74181.md) and the original
[specification](../74181.md).

`ttl_74x181` wraps the existing `alu_74181` module. Its `cn`, `cn_p_4`,
`p_n`, and `g_n` ports are **active low**. This deliberately follows the
manufacturer convention used by the verified original implementation.
The wrapper has no separate ALU implementation. Its test enumerates all
16,384 input vectors against the existing independent datasheet function table.
