# 74x2526: eight-output clock driver with input multiplexer

First introduced: Unknown. [National 1990 FACT Data Book](https://www.bitsavers.org/components/national/_dataBooks/1990_National_FACT_Databook.pdf), PDF page 445,
printed 4-338, is an advance-information entry. It describes two clock inputs,
CK0 and CK1, a selector SEL and eight outputs, but supplies no truth table or
gate diagram identifying which input a given SEL level selects. Implementation
remains pending rather than assuming conventional mux polarity. This is a
required digital function; it is not an analog exclusion.
