It independently enables the lower and upper five-bit halves of a ten-line bidirectional bus. This model preserves the source's digital connectivity controls and bidirectional paths. It is a passive switch network, not a directed Boolean mux.

## Controls and topology

BEA_n and BEB_n are active-low bus-switch enables. BEA_n controls lanes 0–4; BEB_n controls lanes 5–9.

| BEA_n | BEB_n | A0–A4 ↔ B0–B4 | A5–A9 ↔ B5–B9 |
|---:|---:|---|---|
| 1 | 1 | Isolated | Isolated |
| 0 | 1 | Connected | Isolated |
| 1 | 0 | Isolated | Connected |
| 0 | 0 | Connected | Connected |

Port mapping: Port 0 is A0–A9 and port 1 is B0–B9; lane k is flattened bit k in each port. Flattened bus offset details: A=indices 0–9; B=10–19.

## Model contract and limits

`external_data` and `external_drive` describe external strong digital drivers only; do not feed a prior resolved value back as a new source. `resolved`, `valid`, `conflict`, and `weak_drive` use the flattened port ordering above. Ports joined by enabled switch paths form one connected component in each lane. Equal strong drivers resolve normally. Opposite strong drivers set `conflict=1`, `valid=0`, and masked `resolved=0` on every member. A component with no external source is invalid; this device supplies no modeled weak pull, so `weak_drive` is always zero.

ASSUMPTION: All external values are already valid Boolean logic levels and controls are settled. The QS sheet identifies QST3584 as the 25-ohm low-noise version of the ten-bit bus switch and shows direct A/B FET paths. The digital model treats enabled lanes as ideal zero-delay bidirectional connectivity and omits resistance, analog input/output limits, timing, and transient effects. The library applies its global passive-network rule: resolve the whole connected topology once from external sources rather than cascading already-resolved outputs.

## Verification

The self-checking test independently builds connected components from the source-derived switch table, then checks all four control combinations, floating lanes, one-source propagation from each port and lane in both polarities, opposite-source conflicts for every port pair, and 96 deterministic mixed-drive patterns per control mode. It compares both endpoints and checks `valid`, `conflict`, `resolved`, and `weak_drive`.
