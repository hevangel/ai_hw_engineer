## Logical contract

A-to-B and B-to-A are independently controlled 18-bit paths. `a_in[17:0]` and `b_in[17:0]` correspond to A1..A18 and B1..B18; each output bus is paired with a positive drive flag. The native overbars are represented by `_n` signal names:

- `oeab_n=0` enables B outputs; `oeab_n=1` releases B. `oeba_n` does the same for A.
- `leab=1` makes A-to-B data transparent; `leba=1` makes B-to-A data transparent.
- With the corresponding latch enable low, a falling edge of the overbarred clock pin (`clkab_n` or `clkba_n`) stores data if the overbarred clock-enable pin is low (`clkenab_n=0` or `clkenba_n=0`). Otherwise stored data holds.

The outputs are non-inverting. `a_drive = !oeba_n` and `b_drive = !oeab_n`; enabling both directions is represented independently. When not driving, the associated output value is masked to zero and must be ignored. Storage has unspecified power-up contents, so consumers must initialize it through a transparent mode or an enabled clock event before relying on stored data. Timing, voltage levels, drive strength, and package details are omitted.

ASSUMPTION: The function table documents transparent operation with `LE=H` and clocked storage with `LE=L`; input setup/hold and qualified mode transitions are assumed. The RTL models the latch/transparent path as tracking the bus while `LE=H`, and clock-enabled storage while `LE=L`.
