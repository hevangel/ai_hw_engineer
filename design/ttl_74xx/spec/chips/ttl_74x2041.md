## Native digital contract

Per the description, the enable/disable logic partitions the device as two
3-bit sections and one 1-bit section. Section 1 is bit 0 (pins 1AI1/1AO1/1B1),
section 2 is bits 3:1 (2AI1..2AI3/2AO1..2AO3/2B1..2B3), section 3 is bits 6:4
(3AI1..3AI3/3AO1..3AO3/3B1..3B3). `ai_in[6:0]` observes the A-input pins and
`ao_out[6:0]` drives the A-output pins in that bit order; `b_in[6:0]` observes
resolved BTL pins in the same bit order (1 = line released by every driver,
0 = asserted low). `oea[2:0]` holds the three active-high A-output enables
(bit 0 = 1OEA pin 47, bit 1 = 2OEA pin 20, bit 2 = 3OEA pin 24) and
`ao_drive[2:0]` reports the resulting per-section bank-enable flags.
`oeb_n[2:0]` holds the three active-low per-section B enables (bit 0 = 1OEB_n
pin 45, bit 1 = 2OEB_n pin 25, bit 2 = 3OEB_n pin 26). `oeb` is the single
shared active-high B enable (pin 46): the block diagram routes one buffered
OEB to every section's drivers. `b_drive[6:0]` carries per-pin open-collector
sink flags following the 16246 precedent (flag 1 = pin actively sinking its
line low, flag 0 = released); `b_out[6:0]` is always zero.

Each section independently reproduces every row of the function table: B
drivers active iff `oeb=1` and that section's `oeb_n=0` (sink =
`ai_in & ~oeb_n[section] & oeb`), AO drivers active iff that section's
`oea=1` (`ao_out = ~b_in` while enabled). Data is inverted on both paths per
the description: an AI pin high sinks its B line, and the A outputs reflect
the inverse of the data at the B port. The function table is shared by all
sections (inputs OEB, OEB-bar, OEA), and the isolation/transfer row
combinations match the 74x2040 table.

ASSUMPTION: Pin 25 is labeled "2OEB" without an overbar on the pinout page,
but the ANSI/IEEE-91 logic symbol marks it with an active-low polarity
indicator feeding 1EN5, the block diagram draws an inverting input buffer, and
the shared function table requires an active-low OEB-bar per section. Pin 25
is therefore modeled as the active-low section-2 B enable (2OEB_n), identical
in role to pins 45 and 26.

ASSUMPTION: Externally resolved powered logic; a released B line is observed
high only because the board's bias network/pullups resolve it before the pin.
The IEEE 1149.1 pins allocated on the package are no-connects in this
product-preview version (TMS and TCK not connected, TDI shorted to TDO) and
are omitted. BIAS Vcc, BG Vcc, BG GND, the B-port bias network, the 2 ns
minimum edge rate, 100 mA sink current, Vcc < 2.5 V power-off isolation,
thresholds and timing are analog/electrical behavior and are omitted.
