## Reference interface notes (MIT baseline)

# ttl_74x2845 — 8-bit transparent latch with async reset and multiple output enable

8-bit transparent latch with active-low async reset (`rst_n`) and two
active-low output enables (`oe1_n`, `oe2_n`); both must be low for the
outputs to drive.
