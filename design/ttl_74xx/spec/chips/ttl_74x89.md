## Functional baseline and interface notes

# ttl_74x89 — 16x4 RAM with inverted outputs

Outputs are inverted (`data_out_n = ~mem[addr]`). Sync write, async read.
Original chip is async-write with open-collector outputs — neither modeled.


## Integration assumptions

ASSUMPTION: This RAM exposes a normalized synchronous-write/async-read interface. Native asynchronous write pulses are sampled as a `clk` transaction; integration must provide this clock explicitly.
