# 74x681: 4-bit parallel binary accumulator

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [SN74LS681](https://archive.org/details/bitsavers_tidataBookVol2_45945352/page/n1339).
**Status:** pending.

This numbered function belongs to the board-level 74-series logic ecosystem.
Its relevance is the digital 4-bit parallel binary accumulator building block.
See the [library contract](../spec.md), [extension plan](../../plans/extended_plan.md),
[coverage report](../../report/extended_report.md), and [provenance](../../references/README.md).

## Reason

Datasheet not yet accessible via current sources; specific control-pin layout (shift register variants 671-676, ALS-family address comparators 677-680, accumulator 681) needs confirmation before RTL; Datasheet FOUND and correct: TI SN74LS681 (D2422, tidataBookVol2 n1339). NOT a simple accumulator: it is a 4-bit ALU (16 arithmetic + 16 logic ops) plus Word-A register and Word-B shift/accumulator register, carry look-ahead (Cn/P/G/Cn+4), bus-driving bidirectional I/O, 8 register modes (RS0-2), and serial shift (RI/LO, LI/RO). Implementable but a large multi-table effort (needs Tables 1/2/3) - deferred as a bigger task than the rest of this batch.

No RTL stub is supplied for this entry.
