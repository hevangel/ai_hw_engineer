## Functional baseline and interface notes

# ttl_74x166 — 8-bit shift register with sync load, async clear

Like `ttl_74x165` plus an async active-low clear input.


## Load, shift and clock polarity correction

Parallel bit 7 is the first serial output; serial input enters bit 0. `clk_inh` OR-gates the native clock. Change inhibit while clk is high to avoid generating a clock transition. The 74166 parallel load is synchronous; clear is asynchronous. The older reversed serial ordering and synchronous-only 165 description are superseded.
