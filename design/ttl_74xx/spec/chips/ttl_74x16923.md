# 74x16923: 18-bit LVTTL-to-GTL/GTL+ bus transceiver

**Manufacturer source:** Texas Instruments SN74GTL16923, SCBS674G (August 1996, revised August 2001), in the official [TI GTLP design guide SCED004A](https://www.ti.com/lit/ug/sced004a/sced004a.pdf), printed pages 2-41 to 2-50; the package pinout is on book PDF page 62, the function table on PDF page 63, and the logic diagram on PDF page 64. Book PDF SHA-256: `414fb09c44deff6897c9fdf90ea9b59f9f592e5f78067cb4d65d80018799a995`.

An 18-bit registered bus transceiver providing LVTTL-to-GTL/GTL+ and
GTL/GTL+-to-LVTTL translation, partitioned as two 9-bit transceivers with
individual output-enable controls and common D-type flip-flop storage controls.
The earlier catalog download for this number contained 16912 content; the
function here is taken from the SN74GTL16923's own section in the design guide.

## Logical contract

The A port is LVTTL (push-pull); the B port is GTL/GTL+ and sinks only (the
source lists 100 mA low-state B-port current and no B-port high-state drive).
`a_in[17:0]`/`b_in[17:0]` observe package pins in order; bank 1 is bits [8:0]
(1A/1B pins) and bank 2 is bits [17:9] (2A/2B pins). `oeab_n[0]`/`oeba_n[0]`
(overbarred 1OEAB/1OEBA, active low) enable bank 1's outputs and
`oeab_n[1]`/`oeba_n[1]` enable bank 2's. `ceab_n`/`ceba_n` (overbarred
CEAB/CEBA, active low) qualify storage and are common to both banks, as are
`clkab`/`clkba`. `a_out`/`a_drive[1:0]` carry the B-to-A push-pull output
state per bank; `b_drive` is the A-to-B low-only sink mask.

Per the function table (A-to-B shown; B-to-A similar):

| CEAB_n | OEAB_n | CLKAB | B output | Mode |
|---|---|---|---|---|
| X | 1 | X | released | Isolation |
| 1 | 0 | X | B0 | Qualified storage inhibited |
| X | 0 | steady H or L | B0 | Hold |
| 0 | 0 | rising | A captured | Clocked storage of A data |

A rising edge captures only while CE is low; output enables gate the bus
drivers alone and never disturb storage. Driving the two banks' enables to
opposite states isolates each 9-bit bank independently.

VREF is an analog reference and is omitted from this pure-digital contract.

ASSUMPTION: Native setup/hold windows are not modeled; register contents power
up unspecified. `b_drive` is an explicit low-only sink indication; board models
must supply termination pullups, resolve the bus, and only then feed `b_in`.
Masked outputs are zero and ignored by board adapters.
