## Local model contract

The model is a normalized digital function interface, not a certified native
package-pin replica. Electrical families, propagation delays and analog effects
are omitted. Native active edges and asynchronous resets are exceptions to the
library's generic reset convention. Storage has unspecified power-up contents
unless the contract explicitly initializes it. Three-state data must be used
with its drive mask; split bus inputs/outputs require board-level resolution.

## Reference interface notes (MIT baseline)

# ttl_74x311 — memory chip

16-word x 9-bit RAM. Sync write on posedge `clk` when
`!cs_n && !we_n`; async read. `INIT_FILE` parameter loads contents.

## Local output-latch contract

ASSUMPTION: The normalized positive-data interface uses `latch_en=1` to make
the output latch transparent; `latch_en=0` holds the captured word while the
address or RAM contents change. Writes remain synchronous to `clk` with both
`cs_n` and `we_n` low. Output selection masks the held word without changing it.
This explicit transaction interface supersedes the baseline combinational-only
RAM interface and requires external mapping to the native package controls.
