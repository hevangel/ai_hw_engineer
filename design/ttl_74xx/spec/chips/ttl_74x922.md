# 74x922: 16-key encoder

**First introduced:** Unknown; exact launch year has not been established.
**Manufacturer reference:** [National Semiconductor MM54C922/MM74C922 16-key
encoder, MM54C923/MM74C923 20-key encoder, 1977 National CMOS
Databook](https://bitsavers.org/components/national/_dataBooks/1977_National_CMOS_Databook.pdf),
printed pages 1-136 to 1-139, PDF pages 151-154 (one-based). SHA-256:
`3e8c5ec749791505ac253578b0a12aeb0411f7f33272dfb8df35bd7f5e684227`.
Connection diagrams on PDF page 151; switching-time waveforms (Figure 1
debounce/rollover, Figure 2 output-enable) on PDF page 153; block diagram and
full 20-position truth table on PDF page 154. The same combined datasheet
with additional application pages appears in the [1981 National CMOS
Databook](https://bitsavers.org/components/national/_dataBooks/1981_Natonal_CMOS_Databook.pdf)
(SHA-256 `7330b1a886d14e2c9037679942d911972219990be182661f786f633bad457ae6`,
PDF pages 179-185), visually reviewed for consistency.
**Status:** implemented.

The MM74C922 scans a 4x4 SPST switch matrix (X1-X4 column drives, Y1-Y4 row
senses with internal pull-ups), debounces one closure with a single external
KBM capacitor, latches the key code into a last-key register, and signals it
on DATA AVAILABLE with two-key rollover. The scan can be clocked externally
on the OSCILLATOR pin, which is the modeled interface.

## Native digital contract

`osc` is the OSCILLATOR pin (5) driven by an external clock; each rising edge
is one scan tick. `row[3:0]` observes Y1-Y4 (pins 1-4, Y1 in bit 0); the
board models the pull-ups, so an open row reads 1. `col_n[3:0]` are X1-X4
(pins 11,10,8,7; X1 in bit 0), active-low column drives, exactly one low at a
time. `oe_n` is Output Enable (pin 13, active low per Figure 2). `data[3:0]`
is DATA OUT {D,C,B,A} (pins 14-17; A least significant in bit 0) with
`data_drive`; `da` is DATA AVAILABLE (pin 12, high = valid entry).

Scanning: a 2-bit scan counter drives the columns in the repeating sequence
X1,X2,X3,X4. A key at (row r, column c) is detected on a tick whose driven
column is c while `row[r]` is low, per the block diagram column-scan, row-sense
structure.

Debounce and entry: a candidate key must be detected on `DEBOUNCE_CYCLES`
consecutive visits of its column to be accepted (`DEBOUNCE_CYCLES` = 0
accepts on the first detection, modeling the source's "defeated by omitting
the capacitor"; visits between the candidate's column scans retain the
candidate). On acceptance the truth-table code is latched into the last-key
register, `da` rises, and the key becomes the entered key. While the entered
key stays closed, `da` stays high. When the entered key is observed open at
one of its column visits, `da` falls — even if another key is depressed.
Data outputs always show the last-key register ("last key register at
outputs"), unaffected by `da`.

Two-key rollover: a second key pressed while the first holds is debounced as
a candidate; when it has been debounced and the entered key has been
released, it is accepted: the register takes the new code and `da` rises
again after the low period, matching Figure 1's T1/T3 sequence.

Key codes (truth table, PDF page 154): key at row r (Y1=0..Y4=3), column c
(X1=0..X4=3) latches {D,C,B,A} = {r[1],r[0],c[1],c[0]} — column code on
B,A; row code on D,C.

ASSUMPTION: The KBM pin (6) and its RC mask (T1 = T2 = RC, T3 = 0.7 RC, R =
10k, C external) are analog and outside the contract; the debounce is
normalized to column-visit counting with the `DEBOUNCE_CYCLES` parameter
(house 74x4060 oscillator precedent). The scan starts at X1 and ascends; the
source does not state the phase order of the 2-bit counter. The OSCILLATOR
pin's active edge is not specified; rising edges tick the scanner. The
power-up level of DATA AVAILABLE is not stated; the model defines low, the
only level consistent with "goes high when a valid keyboard entry has been
made", and registers initialize their control state (not the last-key
register, which powers up unspecified) accordingly. If two keys on the same
driven column are closed simultaneously, the lowest-numbered row is detected.
Behavior with three or more simultaneous keys is unspecified in the source
beyond two-key rollover. Figure 2 tri-state timing is analog; disabled
`data` is zero with `data_drive` 0. `da` is not affected by `oe_n`.
