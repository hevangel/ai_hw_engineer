# 74x16292: 12-bit 1-of-2 FET multiplexer/demultiplexer

First introduced: Unknown; the manufacturer publication date is not a confirmed
initial-shipment date. Primary source: [SN74CBT16292](https://www.ti.com/lit/ds/symlink/sn74cbt16292.pdf), table pages
1–2. SHA-256 `83934dc3fd6defb5f4a9f820047fee89b6c9d5353e3785e2f6289a6de02929b3`.

FET bus switches provided low-delay board interconnects and memory-bus exchange
without directional logic buffers. This model retains their complete digital
topology and resolves both directions, including simultaneous connections.

## Control and port mapping

control[0]=S. Ports: A, B1, B2. The selected B port connects to A; the unselected B port has a weak pulldown.
There are 3 ports, each 12 bits. Port index 0 is A (or A1 where noted).
`external_data[port*12+bit]` and `external_drive[port*12+bit]` describe **external
strong drivers only**. They must not be fed from a previous resolved bus value.
`resolved`, `valid`, `conflict`, and `weak_drive` use that same flattened ordering.

| Control | Connected port groups |
|---|---|
| 0 | channel 0 onward: 0=1 |
| 1 | channel 0 onward: 0=2 |


Connected components share their driven digital level. With conflicting strong
zero/one drivers, `conflict=1`, `valid=0` and `resolved=0` for every member of the
component. With no source, `valid=0`; floating data is masked zero. Equal multiple
drivers are valid. `weak=1` only when resolution uses a weak internal bias and
there is no strong driver.  The unselected B port's native resistor is represented by a weak zero;
it yields to strong external drivers. Make-before-break analog overlap is omitted.

ASSUMPTION: Ideal valid digital levels and settled controls; analog ON resistance,
threshold translation, delay and transient overlaps are excluded. Board networks
must combine all passive connections before resolving external drivers; cascading
already-resolved values as new drivers does not model a passive network correctly.
The topology is combinational and has no reset or invented clock.
