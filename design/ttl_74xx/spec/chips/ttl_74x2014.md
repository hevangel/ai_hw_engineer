# SN74GTL2014: 4-channel bidirectional GTL/LVTTL transceiver

**Historical date:** TI datasheet SCLS746A is dated February 2014 and revised October 2014; the exact product introduction date is not established here.
**Manufacturer source:** [TI SN74GTL2014 datasheet](https://www.ti.com/lit/gpn/sn74gtl2014), pin functions p. 3 and functional block/modes pp. 8–9.
**Status:** implemented as a digital logic model.

## Function

Four lanes are ordered by bit index: bit 0 is channel 0 through bit 3 channel 3. `DIR=0` selects GTL-to-LVTTL receive: A outputs the sampled B bus and B is not driven. `DIR=1` selects LVTTL-to-GTL transmit: A is an input and B is enabled as an open-drain GTL output. In transmit mode, B sinks low for A=0 and releases for A=1. The module exposes `b_output_enable` separately from `b_drive_low` so an enabled released high is distinct from an input/disabled B port. In receive mode, `a_output_enable` is asserted and `a_output_data=b_bus_in`.

## Scope assumptions

Power is valid, DIR is a stable binary input, and GTL bus samples are already classified using the selected VREF. Released B buses are treated as high by an external pull-up. Analog thresholds, output current, bus termination, timing, power-up state, and contention are not modeled. Supply and VREF pins are abstracted away.
