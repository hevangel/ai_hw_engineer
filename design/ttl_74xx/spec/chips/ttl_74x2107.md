# SN74GTL2107: 12-bit GTL/GTL+ to LVTTL translator with open-drain outputs

**Historical date:** TI datasheet SCLS699 is dated July 2006; the product's exact first-introduction date is not established here.
**Manufacturer source:** [TI SN74GTL2107 datasheet](https://www.ti.com/lit/gpn/sn74gtl2107), function tables p. 2 and logic symbol p. 3.
**Status:** implemented as a digital logic model.

## Function

Vector bit 0 is channel suffix 1 and bit 1 is suffix 2. Open-drain `_drive_low` outputs sink low when one and release when zero. LVTTL OD buses resolve as `drive_low ? 0 : external_drive ? external_data : 1`; GTL input levels are already classified against VREF.

- The first four LVTTL outputs are open drain: `ao_1_2_drive_low[i] = en1 & !bi_1_2[i]`; `ao_3_4_drive_low[i] = en2 & !bi_3_4[i]`. A released output represents table level H, including when its enable is low.
- `ao_9=bi_9` is the push-pull exception on pin 15.
- For channels 5 and 6, `a_5_6_drive_low[i] = en2 & !bi_5_6[i]`; the observed LVTTL bus feeds `bo_7_drive_low[i] = bi_5_6[i] & !a_5_6_bus[i]`. EN2 disables only the 5A/6A output drive, not the external-bus sensing path to 7BO.
- `bo_8_drive_low = !ai_8`.
- `bo_10_drive_low[i] = !(ai_10[i] & bi_9)` for independent AI1/AI2 channels.
- `a_11_drive_low = bi_11`; `bo_11_drive_low = a_11_bus`.

The datasheet's pin description says outputs are open drain except inputs and pin 15 output. The 7BO path includes a glitch-suppression delay; only stable Boolean behavior is modeled.

## Scope assumptions

Valid power and reference voltage are assumed. Bus thresholds, pull-up/termination behavior (beyond logical released-high resolution), power-up isolation, edge/timing behavior, drive strength, and analog contention are excluded. The package's power pins are omitted.
