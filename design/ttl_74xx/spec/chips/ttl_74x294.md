## Functional baseline and interface notes

# ttl_74x294 — Programmable frequency divider

Functionally identical to `ttl_74x292`.


## Reviewed digital contract

Programming code n selects division by 2**n; codes 0/1 inhibit. The 294 supports n up to 15. The normalized `clk` represents the OR-gated native CLK1/CLK2 clock. Test-point pins and live mode-change ripple transients are not exported. Clear when changing the divisor. TI SDLS153A (January 1981) pins these ratios; the baseline had a factor-of-two error.
