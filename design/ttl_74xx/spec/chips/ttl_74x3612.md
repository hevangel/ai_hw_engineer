# ttl_74x3612 — 4608-bit bidirectional FIFO memory (2x64x36)

Bidirectional FIFO: two independent 64-deep x 36-bit queues
(A→B and B→A) sharing a common reset.  Same structure as
[ttl_74x2235](ttl_74x2235.md).
