## Local model contract

The model is a normalized digital function interface, not a certified native
package-pin replica. Electrical families, propagation delays and analog effects
are omitted. Native active edges and asynchronous resets are exceptions to the
library's generic reset convention. Storage has unspecified power-up contents
unless the contract explicitly initializes it. Three-state data must be used
with its drive mask; split bus inputs/outputs require board-level resolution.

## Independent local verification

The manufacturer [TI SN74HC595 datasheet](https://www.ti.com/lit/ds/symlink/sn74hc595.pdf)
specifies separate rising shift/storage clocks, an asynchronous shift-register
clear, and an output enable which does not clear either register. Local tests
cover all byte values, serial order, each independent clock, disabled outputs,
clear preserving storage, and simultaneous-edge old-shift capture. The active
serial output remains available while parallel outputs are disabled.
