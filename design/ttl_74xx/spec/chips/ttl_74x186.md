## Functional baseline and interface notes

# ttl_74x186 — 512-bit ROM (64x8)

64-word x 8-bit mask-programmable ROM. `INIT_FILE` parameter is a
`$readmemh` file path.


## Read-only implementation correction

The model is a 64×8 read-only memory with **no runtime write port**. `INIT_FILE` selects its mask/fuse image. `DEFAULT_WORD` defines an explicit blank image when no image is supplied; no historical mask or erased-fuse polarity is implied. The test image is synthetic address-decoder data, not historical content. The imported writable-memory description above is superseded.
