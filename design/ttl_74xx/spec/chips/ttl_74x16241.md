# 74x16241: 16-bit non-inverting buffer/driver with four grouped output enables

**Manufacturer source:** Texas Instruments SN54ABT16241A / SN74ABT16241A, SCBS096G (February 1991, revised October 1998), [official TI datasheet](https://www.ti.com/lit/ds/symlink/sn74abt16241a.pdf). The function tables and logic symbol are on p. 2; the package pinout is on p. 1. PDF SHA-256: `ea6756e68e237fe5539ef254f15af2e5fa79c3a8b2135e10ced9f3b353bd900a`.

## Logical contract

This is a non-inverting, 16-bit driver divided into four independent 4-bit groups. Package groups `1A1..1A4` through `4A1..4A4` map in order to `a_in[3:0]`, `[7:4]`, `[11:8]`, and `[15:12]`; `y_out` uses the corresponding output ordering. `y_drive[0]..[3]` indicate whether groups 1..4 are driving.

The pins preserve the unusual mixed enable polarity from the TI tables:

| Group | Native enable | Output enabled when | Output |
|---|---|---:|---|
| 1 | `oe1_n` | 0 | `y_out[3:0] = a_in[3:0]` |
| 2 | `oe2` | 1 | `y_out[7:4] = a_in[7:4]` |
| 3 | `oe3` | 1 | `y_out[11:8] = a_in[11:8]` |
| 4 | `oe4_n` | 0 | `y_out[15:12] = a_in[15:12]` |

When a group is disabled, its drive bit is 0 and its data output is masked to zero. Board-level bus resolution uses the drive mask; analog voltage, output strength, propagation delay, and power-up sequencing are outside this digital contract. The part contains no state or reset.
