# 74x2010: 10-channel NMOS bidirectional level translator

**First introduced:** Unknown; the datasheet publication date is not verified as the first-shipment year.
**Manufacturer reference:** [SN74GTL2010 datasheet](https://www.ti.com/lit/gpn/sn74gtl2010), TI document SCDS221 (September 2006). SHA-256: `9abbafd1f198454d42e1af0d74192721af79b80165cd6f917e6076faaa253ddb`.

The GTL2010 contains ten matched NMOS pass transistors with a shared reference-controlled gate network. It has no per-channel direction or enable input: each S/D channel pair supports bidirectional low-level transfer. TI specifies the device for level translation between GTL/GTL+, LVTTL/TTL, and 5-V CMOS levels. The reference transistor establishes the low-side clamp level and is separate from the ten data channels.

## Digital interface and channel behavior

This model exposes two groups of ten digital ports. Flat vector index `channel` is `S(channel+1)` and index `10+channel` is the matching `D(channel+1)`, for channels 0–9. `external_data` and `external_drive` describe external Boolean sources only. They must not be fed from a prior `resolved` output. The `resolved`, `valid`, `conflict`, and `weak_drive` vectors use the same flat mapping.

With valid bias and Boolean levels, each S/D pair is one passive connected component:

| S-side external source | D-side external source | Result on both ports |
|---|---|---|
| Floating | Floating | `valid=0`, `resolved=0` |
| Driven 0/1 | Floating | Driven value, `valid=1` |
| Floating | Driven 0/1 | Driven value, `valid=1` |
| Same driven value | Same driven value | Driven value, `valid=1` |
| Opposite driven values | Opposite driven values | `conflict=1`, `valid=0`, `resolved=0` |

Channels resolve independently. This Boolean connectivity abstraction models the low-resistance ON path in both directions. It does not assert that an unpulled physical NMOS port reproduces a valid high voltage. External pull-ups and other board sources must be supplied through the external-driver interface when their logical effect is wanted. `weak_drive` is always zero because the IC has no internal channel pull-up or pull-down in the documented topology.

## Operating assumptions and limits

The datasheet pin listing maps S1–S10 and D1–D10 as the ten corresponding I/O pairs, with separate SREF, DREF, and GREF pins (pp. 1–2). Its functional tables show the channel transistors off with a disabled reference condition and on for low-level transfer when the reference bias is established; the high level depends on SREF and external pull-ups (p. 3). This model omits analog reference pins and assumes a valid settled operating bias: GREF is tied to DREF and biased high, SREF is set to the intended low-side reference, and the operating conditions meet TI's recommendation that GREF be at least 1.5 V above SREF for best translator operation.

**ASSUMPTION:** The analog bias network is correctly configured and each external voltage has already been classified as a Boolean 0 or 1. The model abstracts enabled channel behavior as ideal, zero-delay connectivity. It omits voltage clamping, thresholds, analog pull-up strength, capacitance, propagation delay, transient overlap, hot-insertion behavior, and contention current. `external_drive=0` means no modeled external source; external resistor networks are not inferred. The model reports digital contention as `conflict` rather than modeling its analog electrical result.
