# 74x2411: 11-bit MOS memory driver, inverting

**First introduced:** Unknown; TI's June 1990 product-preview date does not establish first shipment. **Primary source:** Texas Instruments, *SN54BCT2411/SN74BCT2411 11-Bit MOS Memory Drivers With 3-State Outputs*, printed p. 10-31 (PDF page 750), in the [1991 Advanced Logic and Bus Interface Logic data book](https://archive.org/details/TexasInstruments-TI-Data-AdvancedLogicandBusInterfaceLogic1991OCR/page/n749). PDF SHA-256 `F54A1B538AFF4DF63BBA5A1F79982E8B9A643842E3A70E97AEE00C422074509B`.

## Contract

`a[0]`..`a[10]` map A1..A11 and `y[0]`..`y[10]` map Y1..Y11. The two native active-low enables `g1_n` and `g2_n` are independent input pins but jointly control the entire output bank: all 11 outputs are active only when both are low. If either is high, all outputs are high-impedance. When active, every Y bit is the complement of its corresponding A bit. `drive` indicates each output's three-state status; disabled output data is zero and must be ignored when `drive` is low.

The TI page's text and positive-logic diagram specify the common two-input AND of active-low enables and the inverting data path; it does not provide a separate truth-table block. The modeled interface is digital only. It omits the specified 25-Ω series output resistors, analog drive characteristics, timing, and contention. The device is combinational and has no power-up state.

## Verification

The independent testbench exhaustively checks all 2,048 data vectors for all four enable combinations (8,192 cases).
