# 74x871: dual 16-by-4 register files

First introduced: Unknown. The December 1982 / revised December 1983 document
does not establish first shipment. Primary source: TI 1984 TTL Data Book volume 3,
[D2661](https://archive.org/download/bitsavers_tidataBookVol3_25840031/1984_The_TTL_Data_Book_Vol_3.pdf), PDF pages 646–648 / printed 2-613–2-615.
SHA-256: `da11f2debaf1ff08445e3e73aaab73a01338f43791cc9c96ed60051e996ef79d`.

These devices support Multibus data movement and overlapping register-file access.
Each of the two 16-word, 4-bit files has its own asynchronous address and write
enable. Both ports can independently select either file.

## Native interface

`address_1` and `address_2` map 1A3..1A0 and 2A3..2A0. `write_n[0]` is 1W_n,
`write_n[1]` is 2W_n. `select[3:0]={S3,S2,S1,S0}`. S0 selects A's file
(0=file 1, 1=file 2); S1 selects B's file. S2 high makes A an input and disables
its output; S3 high does the same for B. Each low write enable opens a transparent
write window only if an input port routes to that file. With both input ports
selecting one file, B has priority. An unselected file holds even with W_n low.
Reads are combinational at the selected file's own address, including when the
other port is writing the same file. There is no clock or reset pin.

`a_in`/`a_out` and `b_in`/`b_out` split the package data buses; bit 0 maps suffix 1
and bit 3 suffix 4. `a_drive` and `b_drive` are positive output enables; disabled
data is masked to zero. The 870 uses bidirectional A and B package pins. The 871
has separate DA/QA package pins for A, retaining the same S2-controlled mode table.

ASSUMPTION: Valid powered, noncontentious bus levels and native setup/hold timing.
Addresses and routing selects remain stable through a write pulse as specified;
data is stable before the closing W_n rising edge. Within the open window, the
Boolean model follows selected data. Analog hazards and pulse-width limits are
omitted. Power-up memory is unspecified; initialize through writes.
