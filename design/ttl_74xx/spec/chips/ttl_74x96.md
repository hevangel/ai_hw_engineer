## Functional baseline and interface notes

# ttl_74x96 — 5-bit shift register with async OR-preset

Five-stage right shift. Async active-low clear; async preset that
OR-loads `pre_d` into `q` (set bits become 1; bits already 1 stay 1).
This matches the bit-by-bit async preset in the original datasheet.


## Local contract corrections

Each preset input sets its bit asynchronously; preset data changes remain effective while preset is asserted. Independent bit set controls implement storage without feeding Q back into async preset data.
