# 74x952: dual rank 8-bit shift register, synchronous clear

First introduced: Unknown; the source book establishes documented availability,
not a confirmed first-shipment date. [Manufacturer artifact](https://archive.org/download/NationalSemiconductorLogicDatabook1981/National%20Semiconductor%20Logic%20Databook%201981_text.pdf), PDF pages 419–424 / printed 6-243–6-248; truth tables PDF 422.
SHA-256: `f0c778bf290206981394438a0c273e670ead9c923dc73bf656eb6f2f58dee331`.

These parts made board-level bus readback, diagnostic scan and buffered data
movement available without a processor or a custom logic array.

## Native digital contract

Two
8-bit ranks A and B update on rising `clk`. `io_in[0]` is I/O1 and index 7 is
I/O8; B1 maps bit 0 and `serial_out` is always B8. `serial_in` enters B1.
All five controls are disable inputs: `dis_o`, `dis_i`, `dis_tu`, `dis_td`, `dis_s`.
The I/O bus drives A only when `dis_i=1,dis_o=0`; input enable dominates output.

With both transfer disables high, input enable loads A while shift enable shifts
B independently. Up-transfer (`dis_tu=0,dis_td=1`) loads A from old B, ORed with
I/O input when input is enabled; serial shifting may happen simultaneously.
Down-transfer (`dis_tu=1,dis_td=0`) loads B from I/O when input is enabled,
otherwise from old A; parallel down-transfer overrides serial shifting.
Both transfer disables low synchronously clear B; A clears when input disabled,
or loads I/O when input enabled. This is the LS952 behavior, not the LS962 swap.
All state holds on falling edges; output direction and serial observation are
combinational. No reset pin or system-clock adapter is introduced.

ASSUMPTION: Valid powered logic levels, setup/hold and noncontentious board buses.
Storage starts unspecified; initialize through native controls. Analog propagation,
voltage thresholds, drive strength and hazards are omitted. Split output data is
zero while its positive drive flag is low; consumers must resolve the actual bus.
