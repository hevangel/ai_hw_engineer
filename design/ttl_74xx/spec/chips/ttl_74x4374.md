## Reference interface notes (MIT baseline)

# ttl_74x4374 — 8-bit dual-rank synchronizer

8-bit register with a second cascaded stage on the same clock domain to
suppress metastability when sampling asynchronous inputs. Behavior is the
same as [ttl_74x3374](ttl_74x3374.md).
