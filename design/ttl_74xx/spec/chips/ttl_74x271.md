## Functional baseline and interface notes

# ttl_74x271 — 2048-bit ROM (256x8)

256-word x 8-bit RAM. Sync write on posedge `clk` when
`!cs_n && !we_n`; async read. `INIT_FILE` parameter loads contents.



## Read-only implementation correction

The model is a 256×8 read-only memory with **no runtime write port**. `INIT_FILE` selects its mask/fuse image. `DEFAULT_WORD` defines an explicit blank image when no image is supplied; no historical mask or erased-fuse polarity is implied. The test image is synthetic address-decoder data, not historical content. The imported writable-memory description above is superseded.
