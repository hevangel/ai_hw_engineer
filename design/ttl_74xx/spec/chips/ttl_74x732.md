# 74x732: 4-bit three-bus multiplexer, inverting

**Status:** implemented as a normalized digital bus model.

The 74F732 is a quad inverting, three-state data multiplexer. Each of four bit slices has A, B and C bus terminals. Select inputs S0–S2 choose one of the six directed transfers or the A-to-B-and-C fanout mode. OEA, OEB and OEC are active-low output enables for the corresponding bus. The complete routing table is transcribed below from the Signetics FAST data manual function table (archive item `bitsavers_signeticsdaManual_57966640`, printed page 6-727 / scan n791); page n790 identifies 74F732 as the inverting version and 74F733 as the non-inverting version.

| S0 | S1 | S2 | Required low output enables | Transfer |
|---|---|---|---|---|
| L | L | L | OEC | A → C |
| H | L | L | OEA | C → A |
| L | L | H | OEC | B → C |
| H | L | H | OEB | C → B |
| L | H | L | OEB | A → B |
| H | H | L | OEA | B → A |
| X | H | H | OEB and OEC | A → B and C |

H and L denote high and low; X is a don't-care. An enabled destination receives the bitwise complement of its selected source. Each bus has an explicit positive `*_drive` flag; a false flag represents high impedance, while the corresponding output data is zero-normalized and ignored.

## Interface and limits

The RTL uses three 4-bit input buses, three 4-bit output values, three positive drive flags, the three select bits, and three active-low output-enable inputs. It models no voltage levels, current sink limits, propagation delay, hazard behavior, or analog three-state cell behavior. The output data interface makes drive state explicit so the enclosing digital bus model can resolve contention and high impedance.
