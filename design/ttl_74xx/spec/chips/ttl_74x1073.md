# 74x1073: 16-bit bus termination array with bus-hold function

First introduced: Unknown; document publication is not a confirmed product launch.
Manufacturer source: [SN74ACT1073](https://www.ti.com/lit/gpn/sn74act1073), pages 1–2.
SHA-256: `2688fe7aa1a48f686748276c4c1ec99611406505a012882b66223a01ac67a059`.

This board-level bus building block supports backplane, memory and peripheral
interconnects. Its digital storage, transfer and enable functions remain useful
independently of electrical family or packaging.

## Logical interface contract

The manufacturer bus-hold function retains the last externally driven logic
level independently on each of 16 bus lines. The normalized `external_data`
and `external_drive` vectors describe strong external bus drivers, not previous
resolved outputs. A driven line updates its hold state asynchronously. An undriven
line uses that held value. `resolved` is the resulting value and `weak_drive`
identifies bits supplied by the weak keeper instead of the external driver.

ASSUMPTION: Analog clamp action has no effect on valid digital levels; strong
drivers override weak bus hold. Uninitialized keepers remain unspecified until
each corresponding line has been driven. No arbitrary power-up zero is imposed.

ASSUMPTION: Data/control setup and hold obey the manufacturer table. Analog
voltage conversion, drive strength, passive damping and package delays are omitted.
Three-state outputs are split into data and positive drive indications; masked
zero data is ignored whenever drive is low. Unreset storage starts unspecified.
