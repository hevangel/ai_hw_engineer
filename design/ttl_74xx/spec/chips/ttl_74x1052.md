# 74x1052: 16-bit Schottky bus-termination array

First introduced: Unknown. Primary source: TI [2011 Logic Status Report](https://www.ti.com/jp/lit/sg/jajt001d/jajt001d.pdf),
PDF page 65, BTA-series table (SN74S1052). The table identifies the part as a
16-bit high-speed Schottky barrier diode bus-termination array, clamped to GND.
SHA-256: `eebc578f093ced277287a47677b4ea3f3c912bd072c0e3cdc49491613d0799d4`.

These passive arrays reduce board-level electrical switching noise. They have no
Boolean state/transfer function. Status: excluded under the user's digital-only
scope. Schottky diode bus-termination clamp array; analog-only behavior outside the user-requested pure-digital scope.
