## Local model contract

The model is a normalized digital function interface, not a certified native
package-pin replica. Electrical families, propagation delays and analog effects
are omitted. Native active edges and asynchronous resets are exceptions to the
library's generic reset convention. Storage has unspecified power-up contents
unless the contract explicitly initializes it. Three-state data must be used
with its drive mask; split bus inputs/outputs require board-level resolution.

## Reference interface notes (MIT baseline)

# ttl_74x763 — Octal buffer/line driver, inverting, complementary enables (OC)

Inverting counterpart of [ttl_74x741](ttl_74x741.md) /
[ttl_74x757](ttl_74x757.md): one bank gated by an active-low
OE, the other by an active-high OE; both produce the bitwise complement
of their inputs.

## Local open-collector correction

Disabled output banks release the collectors, represented as logical ones with
a pull-up. Board-level resolution is wired AND. Baseline zero-on-disable behavior
incorrectly sank the disabled bus and is superseded. All 256 data values and all
four bank-enable combinations are tested.
