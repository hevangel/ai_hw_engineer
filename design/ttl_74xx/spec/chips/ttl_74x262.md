## Functional baseline and interface notes

# ttl_74x262 — memory chip

128-word x 45-bit RAM. Sync write on posedge `clk` when
`!cs_n && !we_n`; async read. `INIT_FILE` parameter loads contents.



## Reviewed digital contract

`drive_en` is the per-bit output-drive mask: 1 drives, 0 releases. The data output keeps its deterministic masked-zero value while disabled. For a resolved external bus use `drive_en[i] ? data[i] : 1'bz`. This avoids confusing a disabled output with a driven zero.

## Read-only implementation correction

The model is a 128×45 read-only memory with **no runtime write port**. `INIT_FILE` selects its mask/fuse image. `DEFAULT_WORD` defines an explicit blank image when no image is supplied; no historical mask or erased-fuse polarity is implied. The test image is synthetic address-decoder data, not historical content. The 74262 exports one 45-bit character bitmap per address; the actual teletext character mask must be supplied as an image by an integrating system. Native row/column scan pin mapping is outside this normalized interface. The imported writable-memory description above is superseded.
