# Surfer Waveform Viewer Documentation

Surfer is a modern, open-source waveform viewer built in Rust using the egui framework. It supports VCD, FST, and other waveform dump formats for viewing digital simulation results.

## Documentation Files

- [Overview](overview.md) - What Surfer is and how to use it
- [Installation](installation.md) - Building and installing Surfer
- [Usage Guide](usage.md) - Viewing waveforms, navigation, and features
- [Integration](integration.md) - Using Surfer with simulators
- [Self-hosted Web Viewer](self-hosted-web.md) - Run the browser UI and Surver locally in Docker

## Qualified baseline

Surfer 0.7.0, Surver token authentication and the web viewer are qualified; large-waveform measurements are in the baseline record.

Pins, license, compatibility with the other pinned tools, and supported/unsupported behavior are recorded in [EDA tool baseline](../eda-tool-baseline.md) and the probe results in [EDA tool qualification](../eda-tool-qualification.md).
